# 나라장터 입찰 데이터

> 서비스 이름·엔드포인트는 바뀔 수 있다. 구현 전 공공데이터포털(data.go.kr)에서 "조달청 나라장터" 검색 결과로 확인하고 이 파일을 고친다.

## 데이터 출처
- 공공데이터포털의 조달청 나라장터 오픈API (입찰공고정보, 낙찰정보, 계약정보, 사전규격 등)
- 사용자가 직접: data.go.kr 회원가입 → 해당 API 활용 신청 → 서비스키 발급 (코드에 넣지 않고 `.env`)

## 수집 원칙
- 공식 API를 우선한다. 나라장터 웹 화면 크롤링은 이용약관 확인 전에는 하지 않는다.
- 호출 제한(일일 트래픽)을 지키고, 결과는 로컬 DB(SQLite부터 시작)에 쌓아 중복 호출을 줄인다.
- 공고번호+차수를 고유 키로 쓴다.

## 플랫폼 기능 후보 (planner가 우선순위 결정)
- 키워드·업종·지역·금액 조건으로 맞춤 공고 알림
- 마감 임박 공고 정리
- 과거 낙찰가율 통계 (기초금액 대비)
- 관심 공고 관리 / 투찰 일정 캘린더

## 주의
- 낙찰가 "예측"은 참고용임을 화면에 명시한다.
- 업체 정보 등 개인정보가 섞일 수 있으니 저장·노출 범위를 spec에 적는다.
