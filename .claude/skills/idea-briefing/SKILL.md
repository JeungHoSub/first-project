# 수익화 아이디어 브리핑

## 새로움 원칙 (2026-11-18 사용자 지시, 최우선)
- 이 프로젝트는 **새 수익화 아이디어 발굴** 전용이다. 기존 프로젝트(입찰 플랫폼, 게임, 유튜브·쇼츠·음악 업로드, 클로드 강의, 햄버거·음식점)와 **비슷하거나 그 기능·소식인 것은 내지 않는다.**
- 기존 경험(조달·보안개발·식음료)을 써도 되지만, **전혀 다른 시장·다른 발상**일 때만 낸다.
- 기존 프로젝트에 도움 될 소식을 우연히 찾으면 브리핑에 넣지 말고 `TODO.md` 해당 프로젝트 칸에 한 줄만 적는다.
- 아이디어마다 "기존 프로젝트와 다른 점" 한 줄을 붙인다.

## 공통 순서
1. `VISION.md`, `style/profile.md`, `projects/money-ideas/brief.md`, `outputs/feedback.md`, `outputs/idea-pool.md`, 가장 최근 브리핑을 읽는다.
2. 회차별 조사(아래). 웹검색은 **5~8회 이내**.
3. `outputs/briefings/YYYY-MM-DD-{am|noon|pm}.md`로 저장, `idea-pool.md` 갱신, `log.md`에 한 줄 기록.
4. 커밋·푸시한다.
5. 사용자에게 보내는 마지막 메시지 = 브리핑 요약(휴대폰 화면 기준 15줄 이내) + 선택지 질문.

## 회차별 조사
| 회차 | 조사 | 소스 예시 |
|---|---|---|
| 아침 am | 새 아이디어 3개. 최소 1개는 "사람이 반복 수작업으로 하는 일 → 자동화 서비스" 유형 | 해외 소규모 SaaS·1인 사업 사례, 크몽·숨고·탈잉 수요, 네이버 트렌드, 정부 지원사업·공공데이터 |
| 점심 noon | **새 아이디어 3개 추천은 필수** + 사용자가 고른 아이디어(없으면 점수 1위) 1개 심층 요약: 경쟁 서비스·가격대·1~10 실행 단계 중 자동화 가능 단계·필요 비용 | 경쟁사 사이트, 가격표, 커뮤니티 불만글 |
| 저녁 pm | 오늘 정리, 아이디어 상태 변경 제안, 내일 방향 선택지, 피드백 질문 1~2개 | (조사 최소화) |

## 속보 (flash, 09:52·14:52·16:52)
- 웹검색 2~3회만. **새 아이디어**(새로움 원칙 적용) 또는 사용자가 이 프로젝트에서 고른 아이디어 관련 새 소식.
- **22점 이상이거나 중요한 소식일 때만** `briefings/YYYY-MM-DD-flash-HHMM.md` 저장 + 10줄 요약 + 선택지.
- 없으면 파일 없이 "새 소식 없음" 한 줄로 끝낸다(알림 최소화).

## 브리핑 파일 형식
```
# YYYY-MM-DD 아침 브리핑
## 한 줄 요약
## 아이디어 (또는 심층 조사 / 오늘 정리)
### 1. 이름 — 점수 NN/30
- 무엇: / 누가 돈을 내나: / 얼마: 
- 1~10 단계 중 자동화 가능: (예: 7/10, 사람 필요한 단계 적기)
- 근거: [출처](링크)
- 위험:
## 선택지
1. (추천) ...
2. ...
3. 다 별로 → 이유 알려주기
```

## 구글 캘린더
- 사용자가 아이디어를 고르면 검증·출시 일정을 브리핑 끝 "캘린더 등록 제안"에 적는다(날짜·시간·제목).
- Google Calendar 도구가 있는 세션이면 바로 등록(Asia/Seoul), 없으면 메인 세션에서 등록.

## 사용자가 답하면
- `feedback.md`에 기록, `idea-pool.md` 상태 반영.
- 두 번 이상 반복된 취향은 `style-guide` 스킬로 "학습된 선호"에 추가.
- 커밋·푸시.
