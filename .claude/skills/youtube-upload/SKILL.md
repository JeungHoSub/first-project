# YouTube 업로드

> 아래 수치·정책은 바뀔 수 있다. 구현 전에 공식 문서(developers.google.com/youtube)로 다시 확인하고, 다르면 이 파일을 고친다.

## 자동 업로드 준비 (사용자가 직접 해야 하는 것)
1. Google Cloud 프로젝트 생성 → YouTube Data API v3 사용 설정
2. OAuth 클라이언트(데스크톱 앱) 생성 → `client_secret.json` (git에 올리지 않음)
3. 최초 1회 브라우저 로그인으로 토큰 발급 → 이후 자동 업로드

## 알아둘 제약 (확인 기준: 2026-11, 재확인 필요)
- 일일 할당량 기본 10,000 단위, 영상 업로드 1회에 약 1,600 단위 → 하루 약 6개.
- 검수(audit)를 받지 않은 API 프로젝트로 올린 영상은 **비공개로 고정**될 수 있다. 공개 업로드를 하려면 API 감사 신청이 필요하다.
- 쇼츠는 세로 영상 + 짧은 길이로 자동 분류된다.

## 메타데이터 규칙
- 제목: 앞 30자 안에 핵심 키워드. 과장·낚시 금지.
- 설명: 첫 2줄 요약 → 본문 → 출처/크레딧(음악·책) → 해시태그 3개 이내
- 태그: 5~15개
- AI로 만든 사실적인 콘텐츠는 YouTube의 "변경/합성 콘텐츠" 표시 정책을 따른다.
- 예약 업로드 시간은 brief에 적힌 시간대를 따른다.
