# 스타일 가이드 사용법

## 읽기
- `style/style-guide.md` 전체, 특히 "학습된 선호"는 최우선 규칙으로 취급한다.
- `style/samples/`에서 현재 작업과 비슷한 샘플을 1~2개 골라 톤을 맞춘다. `bad-` 파일은 피해야 할 예시다.

## 쓰기(피드백 누적)
사용자가 "이건 이렇게 해줘", "이런 건 싫어"처럼 반복 적용될 피드백을 주면:
1. 한 줄 규칙으로 일반화한다. (예: "문장 끝에 ~요 대신 ~다 체")
2. "학습된 선호"에 `- YYYY-MM-DD [프로젝트] 규칙 (근거: 요약)` 형식으로 추가한다.
3. 기존 규칙과 충돌하면 기존 줄을 고치고 날짜를 갱신한다.
4. 한 번만 해당되는 지시는 적지 않는다.
