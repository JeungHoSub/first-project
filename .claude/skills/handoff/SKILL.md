# 인계 프로토콜

에이전트끼리는 대화가 아니라 **파일**로 결과를 공유한다.

1. 결과물은 `projects/<이름>/outputs/`에 저장한다. 파일명: `<주제>.md` 또는 `epNN-<제목>.md`. 덮어쓰지 말고 수정본은 `-v2` 접미사.
2. `projects/<이름>/log.md` 맨 아래에 추가:

```
## YYYY-MM-DD 에이전트명
- 한 일:
- 결과물: outputs/파일명
- 다음 담당: (에이전트명 또는 사용자)
- 넘길 메모: (다음 담당이 알아야 할 것, 미해결 질문)
```

3. 다음 담당 에이전트는 작업 시작 시 `log.md`의 마지막 항목부터 읽는다.
