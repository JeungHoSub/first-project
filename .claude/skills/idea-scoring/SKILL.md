# 아이디어 점수표 (각 1~5점, 30점 만점)

| 항목 | 5점 | 3점 | 1점 |
|---|---|---|---|
| 지불 의사 | 이미 돈 내고 쓰는 비슷한 서비스가 있고 불만이 보임 | 수요는 보이나 유료 사례 적음 | 돈 낼 사람 불확실 |
| 자동화 가능성 | 1~10 단계 중 8단계 이상 자동 | 5~7단계 | 4단계 이하 |
| 사용량 대비 수익 | 운영비(클로드·API·서버) 월 1만 원 이하 예상 | 월 10만 원 이하 | 그 이상 / 개발에 크레딧 과다 |
| 첫 매출까지 | 2주 이내 | 1~2달 | 3달 이상 |
| 새로움·확장 | 기존 프로젝트와 다른 새 시장이면서 여러 상품으로 확장 | 새롭지만 단발성 | 기존 프로젝트와 비슷함(→ 브리핑 제외) |
| 위험(낮을수록 고득점) | 법·정책 문제 거의 없음 | 확인 필요 항목 있음 | 저작권·사행성·개인정보 리스크 큼 |

## 사용법
- 점수마다 근거 한 줄. 모르면 3점 주고 "확인 필요" 표시.
- 22점 이상: 심층 조사 후보 / 15점 이하: 탈락 제안.
- 기존 프로젝트(게임, 유튜브, 입찰 등)도 같은 표로 매겨 비교할 수 있다.
