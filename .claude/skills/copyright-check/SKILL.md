# 저작권 확인

> 일반 정보이며 법률 자문이 아니다. 애매하면 사용자에게 보고하고 멈춘다.

## 판단 순서
1. **직접 만든 것 / 권리를 가진 것** → 사용 가능. 근거를 brief에 기록.
2. **저작권 만료(퍼블릭 도메인)** → 한국 기준 원칙적으로 저자 사망 후 70년. 저자 사망 연도와 근거 출처를 기록한다. 번역본은 **번역자의 권리**가 따로 있으니 번역자도 확인하거나 직접 번역한다.
3. **허락받은 것** → 라이선스(CC 등) 종류와 조건(출처 표시, 상업적 이용 가능 여부)을 기록.
4. **그 외** → 사용 불가. 대안 제시: 퍼블릭 도메인 작품, 저작권자에게 허락받기, 요약·리뷰 형식(인용 범위는 제한적).

## 기록
`projects/<이름>/rights.md`에 작품별로: 제목 | 저자/작곡가 | 판단 | 근거 | 확인일

## 음악
- YouTube 오디오 보관함 또는 상업적 이용이 허용된 라이선스만 쓴다.
- AI 생성 음악은 그 서비스 약관에서 상업적 이용·YouTube 수익화가 가능한지 확인한다.
