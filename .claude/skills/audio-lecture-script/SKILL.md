# 오디오 강의 대본 작성법

## 구성 (회당)
1. 오프닝 (30초): 지난 회 한 줄 요약 + 오늘 배울 것 한 줄
2. 본론: 핵심 개념 3개 이하. 개념마다 "무엇 → 왜 → 예시 → 한 줄 정리"
3. 클로징 (1분): 오늘 핵심 3줄 복습 + 다음 회 예고 + 실천 과제 1개

## 듣기용 문장 규칙
- 한 문장은 짧게. 한 번 듣고 이해되도록.
- 표, 코드, URL, 기호 나열 금지. 꼭 필요하면 말로 풀어 쓴다. ("슬래시 에이전트" 등)
- 영어 용어는 처음 나올 때 한국어 설명을 붙인다.
- "첫째, 둘째, 셋째"처럼 위치를 알려주는 말을 쓴다.
- 중요한 문장은 한 번 더 반복한다.
- 분량: 1분 ≈ 300자. 10~20분이면 3,000~6,000자.

## 검수 체크리스트
- [ ] 화면 없이 이해되는가
- [ ] 개념이 3개를 넘지 않는가
- [ ] 마지막에 복습이 있는가
- [ ] 기존 회차와 말투가 일치하는가
- [ ] Claude 기능 설명이 최신 사실과 맞는가
