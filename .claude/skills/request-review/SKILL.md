# 검토 요청

## 올리기
`review/QUEUE.md` 표에 한 줄 추가:
`| YYYY-MM-DD | 프로젝트 | [파일명](../projects/<이름>/outputs/<파일>) | 검토 대기 | |`

사용자에게는 3줄 이내로 알린다: 무엇을 만들었는지, 어디 있는지, 특히 봐줬으면 하는 점.

## 반영하기
사용자가 피드백을 주면:
1. 상태를 `승인` / `수정 요청`으로 바꾸고 피드백 열에 요약.
2. 반복될 피드백은 `style-guide` 스킬로 스타일 가이드에 누적.
3. 수정 요청이면 담당 에이전트에게 다시 배정.
