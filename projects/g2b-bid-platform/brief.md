# 프로젝트: 입찰 플랫폼 (나라장터 기반)

## 목표
- 나라장터 입찰 정보를 모아 조건별로 찾고, 알림·분석을 제공하는 플랫폼
- **1단계: 내가 직접 쓰면서 고도화** → **2단계: 기존 유료 입찰정보 서비스보다 싼 값에 지인 업체부터 판매**
- 처음부터 여러 업체가 쓸 수 있는 구조(계정별 관심 조건 분리)로 만들되, 기능은 내가 쓰는 것부터

## 역할 분담
| 단계 | 담당 에이전트 | 하는 일 |
|---|---|---|
| 1 | researcher | 공공데이터 API 목록·제한, 경쟁 서비스(유료 입찰정보 서비스) 기능·가격 |
| 2 | planner | 대상 사용자·MVP 기능·수익 모델 |
| 3 | developer | 데이터 수집기 → DB → 검색/알림 → 웹 화면 |
| 4 | reviewer | 데이터 정확성·보안 점검 |

## 필요한 스킬
- 있음: g2b-bid-data(필수), handoff, request-review
- 필요 시 skill-scout: 알림(카카오톡/텔레그램/이메일) 연동, 배포

## 사용자 준비물
- data.go.kr 서비스키 (나중에 개발 단계에서 안전하게 등록)

## 결정됨 (2026-11-12)
- 대상: 나 → 지인 업체(저가 유료) 순서
- researcher 우선 과제: 경쟁 유료 서비스의 기능·월 요금 비교표 → 가격 책정 근거

## 판매 단계 전 확인할 것
- 사업자 등록·결제 수단, 개인정보처리방침·이용약관
- 공공데이터 이용 조건(상업적 이용 가능 여부, 출처 표시 의무)

## 확인 필요
1. 관심 분야: 내 업종 / 품목 / 지역 (알림 조건의 첫 기준)
2. 첫 기능: A) 맞춤 공고 알림 — 추천 B) 낙찰가 분석 C) 검색 웹사이트
3. 알림 받을 곳: A) 카카오톡 B) 텔레그램 — 가장 쉬움 C) 이메일
