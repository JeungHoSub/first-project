# 조사: 나라장터 오픈API 목록 · 유료 입찰정보 서비스 가격 · 가격 책정 제안

작성: researcher / 2026-11-12 / 대상: g2b-bid-platform

표기: **[확인]** = 출처에서 직접 확인, **[추정]** = 내 추론·기억 기반(검증 필요), **[미확인]** = 못 찾음.

## 한 줄 결론

공식 API는 무료·"제한 없음" 이용허락이라 재판매형 서비스의 데이터 원가는 0원에 가깝지만 개발계정 일 1,000건 제한이라 운영계정 전환이 필수다. 경쟁사 대표 주자(인포21C)는 월 3만 원대(1개월 33,000원, 12개월 환산 월 약 27,500원)라서, 월 1만~2만 원대로 가면 "더 싸게"가 성립한다.

## 조사 한계 (먼저 밝힘)

이 세션에서는 data.go.kr, sankun.com 등 외부 사이트 직접 열람(WebFetch)이 막혀 있었다(호스트 해석 실패, 해당 도메인이 세션 허용 목록에 없는 것으로 보임). 그래서 **웹검색 결과에 요약된 내용**만 근거로 썼다. 아래 (a)의 수치 중 검색에서 확인되지 않은 것은 [미확인]으로 남겼다. data.go.kr을 허용하면 재조사로 빈칸을 채울 수 있다.

### 알아둘 점
- **공공누리 유형은 확인 못 함.** 포털 표기는 "이용허락범위 제한 없음"인데, 이는 공공누리 1유형(출처표시)과 같지 않을 수 있다. 상업적 이용·출처표시 의무가 있는지 서비스별 상세 페이지에서 확인해야 한다. 일반 정보이며 확정 판단은 전문가 확인 필요. (공공누리 개요: [위키백과](https://en.wikipedia.org/wiki/Korean_Open_Access_License))
- **개발계정 1,000건/일은 입찰공고 서비스 기준.** 공고 조회를 페이지(예: 100건씩)로 돌리면 하루 수만 건 공고 수집엔 부족하다. 운영계정 신청(활용사례 등록) 또는 증량신청이 필요하다 ([가이드](https://wikidocs.net/292158), 개인 가이드 수준이라 공식 재확인 필요).
- 개발자 사례: 검색조건 오퍼레이션이 한도를 먼저 넘겨 HTTP 429가 났고 목록 오퍼레이션으로 옮겨 해결했다는 기록이 있다. 오퍼레이션별 한도가 따로인지는 공식 확인 안 됨 [개인 사례] ([GitHub PR](https://github.com/opethianist-stack/policy-fit/pull/54)).
- 조달청은 2013년부터 조달정보 8종을 오픈API로 개방해 왔다 ([보안뉴스](https://m.boannews.com/html/detail.html?idx=53222), 오래된 기사).

## 프로젝트에 주는 의미
- 데이터 비용 걱정은 없지만 **운영계정 트래픽 승인**이 1순위 선결 과제다. 수집기는 목록 오퍼레이션 중심, 증분 수집, 로컬 DB 캐시 설계를 한다(g2b-bid-data 스킬 방침과 일치).
- 가격 경쟁만으로는 약하다. 인포21C가 공동도급사 DB·컨설팅까지 파는 만큼, 우리는 "맞춤 알림 + 낙찰률 통계" 같은 좁은 기능을 싸게 하는 포지션이 현실적이다 [추정].
- 판매 전 공공누리/출처표시 확인, 개인정보(업체 정보) 처리 범위 확인이 필요하다.

## 사용자 확인 필요
1. data.go.kr, 경쟁사 사이트 직접 열람을 허용할지 (세션 네트워크 설정). 허용하면 낙찰·사전규격·계약·사용자정보 서비스의 트래픽·이용허락범위 재조사.
2. 직접 로그인해서 본 요금: 비드프로, 지투비, 키다리, 비드큐의 요금(회원 전용일 수 있음).
3. data.go.kr 계정으로 활용신청 후 실제 적용되는 트래픽 확인(마이페이지).
4. 가격 안 A/B/C 중 선호, 그리고 대상 업종(인건비 구조와 알림 수요가 다름).
5. 법률: 공공데이터 이용허락범위, 개인정보처리방침, 이용약관은 일반 정보 수준이며 확정 판단은 전문가 확인 필요.

## 확인 못 한 것
- 낙찰·사전규격·계약·사용자정보 서비스의 개발/운영 트래픽과 이용허락범위 세부, 오퍼레이션 전체 목록·필드
- 공공누리 유형(1~4유형 중 어디인지)
- 비드프로, 지투비, 키다리, 비드큐 웹 요금
- 서버·알림 단가 실측치 (원가는 추정)
