# 프로젝트: AI·메이커 실험실 (ai-maker-lab)

## 목표
- **돈보다 몰입.** 원리를 파고들고, 직접 손대고, 반복 실험하고, 결과가 바로 보이는 일을 한다 (`style/profile.md` "몰입했던 순간의 공통점").
- 꿈의 공간(Thinking Zone·3D프린터·AI 개발실)을 작게 지금 시작한다.
- 만든 것은 기록해서 나중에 콘텐츠·제품·다른 프로젝트에 재활용한다.

## 결과물 형태
- `outputs/exp-NN-<이름>.md` — 실험 노트: 목표 → 준비물·비용 → 단계 → 결과(사진·수치) → 다음 실험
- 코드·설정은 `outputs/exp-NN-<이름>/`

## 실험 후보 (크레딧 적게, 사용자 PC의 RTX 4090 활용)
| # | 실험 | 몰입 포인트 | 준비물 | 재활용 |
|---|---|---|---|---|
| 1 (추천) | **로컬 AI 비서**: 4090에 로컬 LLM + 음성인식 → 말로 "오늘 한 일/할 일" → 캘린더 정리 | 모델 고르기·속도·정확도 튜닝 | PC만 (무료) | 안 쓰던 다이어리 부활, Claude 크레딧 절약 |
| 2 | **로컬 이미지 생성 작업대** (ComfyUI) | 워크플로 조립, 결과가 바로 보임 | PC만 (무료) | 썸네일·홍보물·3D 모델 원안 |
| 3 | **3D 프린터 입문**: 첫 출력 → 직접 설계한 부품 | 설정값 반복 실험(레시피 R&D와 비슷) | 프린터 30~60만 원대 | 매장·집 수리 부품, 메이커 콘텐츠 |
| 4 | **센서 자동화 장치** (ESP32/라즈베리파이) | 회로·코드·실물 동작 | 부품 2~5만 원 | 무인점포·자판기 관심사와 연결 |

## 담당 에이전트
- 메인 세션 + `developer` (코드·설정), 기록은 메인 세션이 직접
- 필요해지면 `maker-engineer`(하드웨어·3D 설계) 에이전트 추가 검토

## 제약 / 참고
- PC에서 돌리는 작업은 Remote Control로 PC 폴더를 연결하거나 PC의 Claude Code에서 한다.
- 결과물(노트·코드·설정)은 이 저장소에 푸시, 큰 모델 파일·영상은 커밋하지 않고 위치만 기록.
