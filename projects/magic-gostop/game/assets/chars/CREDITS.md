# 캐릭터 일러스트 출처

- 만든 방법: 게임 안 코드로 그린 초상(갓·한복 모양)을 밑그림으로, 공개 이미지 모델로 "한국풍 웹툰 셀화"로 다시 그림 (2026-11-19, 사용자가 위 줄 6장 선택)
- 모델: Lykon/dreamshaper-8 (CreativeML OpenRAIL-M — 생성물 상업적 이용 허용, 라이선스의 사용 제한 조항 준수)
- 빠른 생성: latent-consistency/lcm-lora-sdv1-5
- 설정: img2img strength 0.45, 10 steps, seed 11, 프롬프트는 scratchpad gen4.py와 같음
- 가장자리 6~7% 잘라 400×500 webp로 저장

출시 전 확인: 모델 라이선스가 바뀌지 않았는지 Hugging Face 모델 페이지에서 다시 확인할 것.
