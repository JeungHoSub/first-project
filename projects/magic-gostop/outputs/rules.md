# 매직고스톱 — 기본 고스톱 규칙 + 매직 후보 아이디어

- 작성: game-designer / 2026-11-12
- 상태: 초안 (사용자 검토 전). 규칙 수치 중 `[확인 필요]` 표시는 출처로 교차 확인하지 못한 항목이다.
- 기준: 2인 맞고(웹·AI 1인용 MVP). 3인 고스톱과의 차이는 2절 표에 따로 정리한다.
- 이 문서는 전통 놀이 고스톱 규칙의 정리이며, 특정 상용 게임의 고유 콘텐츠를 옮기지 않았다.

> **돈 개념 없음 (사행성 방지)**
> 이 게임의 점수는 한 판의 승패를 가르는 **게임 내 점수**일 뿐이다.
> 현금·유료 판돈·환전·베팅·점수의 현금 가치화는 규칙에도, 구현에도 넣지 않는다.
> 점수를 걸고 하는 칩, 코인, 랭킹 보상이 필요해지면 현금화와 무관한 연출용 수치로만 쓴다.

## 2. 인원과 분배 (2인 맞고 기본)

| 항목 | 2인 맞고 (기본) | 3인 고스톱 (참고) |
|---|---|---|
| 손패 | 각 10장 | 각 7장 |
| 바닥패 | 8장 | 6장 |
| 더미(뒤집을 패) | 20장 | 21장 |
| 합계 | 10+10+8+20 = 48 | 7×3+6+21 = 48 |
| 승리(고/스톱 가능) 기준 | 7점 이상 `[확인 필요: 앱마다 다름]` | 3점 이상 |
| 박(피박·광박·멍박) | 패자 1명 판정 | 패자 2명을 각각 판정 |
| 고박 | 의미 약함(선택 규칙 R13, 기본 끔) | 고를 부른 사람이 다른 사람의 스톱에 지면 그 사람이 단독 부담 |
| 한 사람 턴 수 | 10 | 7 |

분배 순서
1. 48장을 섞는다.
2. 선(먼저 하는 사람)이 아닌 쪽 → 선 순서로 손패를 나눈다(엔진에서는 순서 무관, 무작위 셔플 후 슬라이스).
3. 바닥에 8장을 앞면으로 깐다. 나머지 20장은 더미(뒷면).
4. **분배 직후 검사**
   - 손패에 같은 월 4장 = **총통** (6.7절).
   - 바닥에 같은 월 4장 = 선택 규칙 R15 (기본: 전체 다시 섞어 재분배).
   - 바닥의 같은 월 3장은 그냥 깔린 상태. 이 월을 손패로 내면 4장을 먹는다 (뻑 먹기와 달리 상대 피를 받지 않는다).
5. 선: 첫 판은 무작위, 이후는 직전 판 승자. 나가리면 직전 선 유지 (R20).

## 3. 턴 진행

한 턴 = **(1) 손패 내기 → (2) 더미 뒤집기 → (3) 먹기 정산 → (4) 고/스톱 판단**.

### 3.1 매칭 기본 원칙
- 같은 월끼리만 짝이 된다. 종류는 상관없다.
- 바닥에 놓인 같은 월 장수를 n이라 하자.

| n | 내는 카드(또는 뒤집은 카드) 처리 |
|---|---|
| 0 | 짝이 없음 → 바닥에 놓는다 |
| 1 | 그 카드와 짝 → 2장을 먹는다 |
| 2 | 둘 중 **한 장을 골라** 짝 → 2장을 먹는다. 나머지 1장은 바닥에 남는다 |
| 3 | 3장 모두와 짝 → 4장을 먹는다 (3장은 뻑이었거나 처음부터 깔린 것) |

- 먹기 선택이 있으면(n=2) 플레이어가 고른다. AI는 가치 높은 카드를 고르면 된다.
- 손패는 바닥에 짝이 있어도 없어도 임의로 낼 수 있다. 짝이 있는데 일부러 다른 패를 내도 된다.

### 3.2 한 턴의 순서 (엔진용)

```
1. 플레이어가 손패 H 1장을 낸다. (또는 폭탄/빈 패, 6.6절)
   H의 월에 대해 바닥 n을 조회해 3.1 표대로 "잠정 처리"한다.
2. 더미 맨 위 D 1장을 뒤집는다. (더미가 비면 이 단계는 건너뛴다)
   D의 월에 대해 바닥 n'(1에서 처리한 뒤 상태)을 조회해 3.1 표대로 처리한다.
   단, H와 D가 같은 월이면 아래 3.3의 특수 결과가 우선한다.
3. 정산: 먹은 패를 내 획득 영역에 넣고, 특수 효과(상대 피 가져오기 등)와 싹쓸이를 처리한다.
4. 점수를 계산해 승리 기준에 도달했으면 고/스톱 선택(5.2절).
5. 상대 턴. 양쪽 손패가 모두 0이 되면 판 종료.
```

### 3.3 H와 D가 같은 월일 때 (특수 결과 표)

| 낼 때 바닥 n (H 처리 전) | H 후 → D가 같은 월 | 결과 | 효과 |
|---|---|---|---|
| 0 | H가 바닥에 놓임 → D가 같은 월 | **쪽** | H, D 2장을 먹고 상대 피 1장 |
| 1 | H와 바닥 1장이 짝 → D가 같은 월 | **뻑** | 먹지 못하고 같은 월 3장이 바닥에 쌓인 채 턴 종료 |
| 2 | H와 바닥 중 1장 짝 → D가 같은 월 | **따닥** | 같은 월 4장을 전부 먹고 상대 피 1장 |
| 3 | (같은 월 4장 모두 H와 바닥 3장) | 불가능 | — |

- 위 표의 "D가 같은 월"이 아니면 H와 D는 각각 3.1 표로 독립 처리된다.
- 뻑이 난 월의 3장은 바닥에 쌓여 있다. 누구든 그 월 카드를 한 장 내거나 뒤집으면 n=3이므로 4장을 먹는다 (6.1절).

## 4. 먹기 판정 요약

- 먹은 카드는 종류별 영역(광/열끗/띠/피)에 쌓는다. 획득 패는 모두 공개 상태.
- 손패, 더미는 비공개. 흔들기(6.5절) 선언 시 해당 월 3장만 공개한다.
- 상대에게 "피 1장을 가져온다"는 효과: **일반 피를 우선** 가져온다. 일반 피가 없고 쌍피만 있으면 쌍피를 가져온다. 상대 피가 0장이면 가져올 수 없다 (빚으로 남기지 않음, 선택 규칙 R18).
- 열끗·띠·광은 피 1장 효과로 빼앗기지 않는다.

## 5. 점수 계산

### 5.1 기본 점수 (획득 패 기준)

| 항목 | 조건 | 점수 |
|---|---|---|
| 광 | 3광(비광 제외) | 3 |
| | 3광(비광 포함) | 2 |
| | 4광 | 4 `[확인 필요: 비광 포함 4광을 3점으로 하는 지역 있음, R03]` |
| | 5광 | 15 |
| 열끗 | 5장 | 1, 이후 1장마다 +1 |
| 고도리 | 2·4·8월 열끗 3장(새 둘, 기러기) | 5 (열끗 장수 점수와 별도로 가산) |
| 띠 | 5장 | 1, 이후 1장마다 +1 |
| 홍단 | 1·2·3월 띠 | 3 |
| 청단 | 6·9·10월 띠 | 3 |
| 초단 | 4·5·7월 띠 | 3 |
| 피 | 10장 | 1, 이후 1장마다 +1 (쌍피는 2장) |

- 위 항목은 **모두 합산**한다. 같은 카드가 여러 항목에 동시에 들어간다 (예: 홍단 3장 + 띠 5장 → 3+1).
- 12월 띠는 띠 장수에만 들어간다.
- 계산 순서와 무관하게 "획득 패의 현재 상태"로 매번 처음부터 다시 계산한다. (상대가 피를 가져가 점수가 줄 수 있다.)

### 5.2 승리 기준과 고/스톱
- 기본 점수(5.1, 고·배수·박 적용 전)가 **7점 이상**이면 자기 턴 정산 직후 선택한다.
  - **스톱**: 판을 끝내고 그 점수로 승리.
  - **고**: 계속한다. 고를 외친 횟수를 기록하고, 그때의 기본 점수를 기억한다.
- 고 이후에는 **자기 점수가 직전 고 시점의 점수보다 늘어난 턴에만** 다시 고/스톱을 고를 수 있다. 늘지 않은 턴은 선택 없이 진행한다.
- 고 이후 상대가 먼저 7점 이상이 되어 스톱하면, 고를 부른 쪽이 패자가 된다 (승자 점수에 내 고는 영향을 주지 않는다).
- 판이 끝날 때(양쪽 손패 소진) 7점 이상인 사람이 한 명이면 그 사람이 승자다. 둘 다 7점 이상이면 기본 점수가 높은 쪽이 승자, 동점이면 나가리 `[확인 필요: 앱마다 다름, 엔진은 단순화함]`.
- 7점은 자기 턴에 도달해야 선택권이 생긴다. 상대 효과로 점수가 7점 미만으로 떨어지면 선택권이 사라진다.
- 아무도 7점 이상이 아니면 **나가리** (5.7절).

### 5.3 고 가산과 배수

| 고 | 가산 | 배수 |
|---|---|---|
| 1고 | +1점 | 없음 |
| 2고 | +2점 (누적 총 +2) | 없음 |
| 3고 | +3점 | ×2 |
| 4고 | +4점 | ×4 |
| 5고 | +5점 | ×8 |
| n고 (n≥3) | +n점 | ×2^(n−2) |

`[확인 필요: 3고 이상의 가산이 "고 횟수만큼"인지 "2점 고정"인지 지역마다 다르다. 선택 규칙 R02.]`

### 5.4 특수 보너스 배수

| 항목 | 배수 |
|---|---|
| 흔들기 1회 | ×2 |
| 폭탄 1회 | ×2 |
| 흔들기·폭탄 여러 번 | 각각 ×2 곱셈 (예: 흔들기 1 + 폭탄 1 = ×4) |

### 5.5 박 (패자에게 불리한 배수)
승자가 정해진 뒤 패자의 획득 패를 기준으로 판정한다. 해당하는 박마다 ×2, 여러 개면 곱한다.

| 박 | 조건 (MVP 기본) |
|---|---|
| 피박 | 승자가 피로 점수를 얻었고(피 10장 이상), 패자 피가 **1~5장** |
| 광박 | 승자가 광으로 점수를 얻었고(3광 이상), 패자 광이 **0장** |
| 멍박(멍따) | 승자 열끗이 **5장 이상**이고, 패자 열끗이 **0장** |

- 국진을 쌍피로 계산하는 쪽은 열끗 장수에서 빠진다 (R04).
- 박 기준은 지역마다 조금씩 다르다. 선택 규칙 R05~R08 참고.

### 5.6 최종 점수 공식

```
기본점수   = 광 + 열끗 + 고도리 + 띠 + 홍/청/초단 + 피            (5.1)
고가산후   = 기본점수 + 고가산                                        (5.3)
배수       = (고 배수) × (흔들기·폭탄 배수) × (박 배수) × (나가리 이월 배수)
최종점수   = 고가산후 × 배수
```

- 패자는 `최종점수`를 게임 내 점수로 잃고 승자는 그만큼 얻는다. 어떤 현금·화폐 가치도 연결하지 않는다.
- 총통은 별도 고정 점수(6.7절).

### 5.7 나가리
- 양쪽 손패가 모두 소진되었는데 승자가 없으면 그 판은 **나가리** (무승부).
- 다음 판 승자의 점수에 이월 배수를 적용한다 (MVP 기본 ×2, 연속 나가리는 ×4까지, R12).
- 나가리 판의 선은 직전 판 선이 유지한다.

## 6. 특수 상황

### 6.1 뻑
- 3.3절 조건(바닥 n=1에 H를 맞추고 D가 같은 월)으로 같은 월 3장이 바닥에 쌓인다. 패널티 없음(MVP), 먹은 패 없이 턴 종료.
- **뻑 먹기**: 쌓인 월의 4번째 카드를 내거나 뒤집으면 4장을 먹는다.
  - 상대가 만든 뻑을 먹으면 **상대 피 1장**.
  - 자기가 만든 뻑을 자기가 먹으면 **자뻑**: **상대 피 2장** (R09).
- 3연뻑(본인이 연속 3번 뻑)은 MVP에서 특수 처리하지 않는다 (R10 기본 끔).

### 6.2 따닥
- 3.3절 조건. 같은 월 4장 전부 + **상대 피 1장**.

### 6.3 쪽
- 3.3절 조건. H, D 2장 + **상대 피 1장**.

### 6.4 싹쓸이
- 한 턴의 정산이 끝난 시점에 바닥이 **0장**이면 **상대 피 1장**.
- 분배 직후나 뻑 직후 판정하지 않고, 턴 종료 때만 본다.
- 더미 소진 후 마지막 턴도 인정 (R16).

### 6.5 흔들기
- 손패에 같은 월 3장이 있고 바닥에 그 월이 0장일 때, 그 월의 카드를 낼 때 선언할 수 있다.
- 선언하면 3장을 상대에게 공개하고 이 판의 배수에 ×2.
- 선언은 선택이다. 선언하지 않고 내도 된다.

### 6.6 폭탄
- 손패에 같은 월 3장이 있고 바닥에 그 월이 1장일 때, 3장을 한꺼번에 낸다.
  - 바닥 1장과 합쳐 **4장 획득**, **상대 피 1장**, 배수 ×2.
  - 폭탄 후에도 같은 턴에 더미 뒤집기를 한다.
- 손패 3장을 한 턴에 썼으므로 **빈 패(더미 뒤집기 전용 카드) 2장**을 손패에 추가한다 (총 턴 수 유지). 빈 패를 내면 H 없이 D만 뒤집는다 (R21).
- 같은 월이 바닥에 0장이면 폭탄이 아니라 흔들기다. 바닥에 2장 이상이면 손패 3장과 합해 5장이 되어 존재할 수 없다.

### 6.7 총통
- 분배 직후 손패에 같은 월 4장이면 총통을 선언할 수 있다.
- 즉시 판 종료, 선언자 승리 **10점 고정** (박·배수 없음, R11).
- 양쪽 모두 총통이면 선이 우선 (나가리 처리도 가능, R11).

### 6.8 국진 (9월 열끗)
- 열끗과 쌍피 두 가지 용도 중 택일. MVP 기본은 **판 종료 정산 때 승자에게 유리한 쪽으로 자동 선택**한다(R04).
- 고도리에는 포함되지 않는다.

## 8. 예시 판 (발췌)

카드 표기: `월+종류` (예: 3띠 = 3월 띠, 9열 = 9월 열끗(국진), 5피 = 5월 피). 선 = A, 후 = B.

분배 (8장 바닥 전체, 손패는 필요한 부분만)

| 영역 | 카드 |
|---|---|
| 바닥 8장 | 3띠, 6피, 9피, 11피, 5열, 7피, 12쌍피, 4띠 |
| A 손패(발췌) | 3피, 5피(두 번째), … |
| B 손패(발췌) | 5피(첫 번째), … |
| 더미(맨 위부터, 발췌) | 9열, 5띠, … |

턴 1 (A)
- 손패 3피를 낸다. 바닥에 3월 3띠 1장 → n=1 → 3피+3띠가 짝 (잠정 처리).
- 더미 뒤집기 → 9열. 바닥 9피 n=1 → 9열+9피를 먹는다. H(3월)와 D(9월)는 월이 다르다 → 독립 처리.
- A 획득: 3피, 3띠, 9열, 9피 (4장). 바닥 6장 → 싹쓸이 아님.

턴 2 (B)
- B가 5피(a)를 낸다. 바닥 5월 5열 1장 → n=1 → 5피(a)+5열이 잠정 짝.
- 더미 뒤집기 → 5띠. H와 D가 같은 월이고 n=1 → **뻑**. 바닥에 5월 3장(5열, 5피a, 5띠)이 쌓인 채 턴 종료. B는 먹은 것이 없다.

턴 3 (A)
- A가 손패의 5피(b)를 낸다. 바닥 5월 3장 → n=3 → **4장 모두 획득**.
- B가 만든 뻑이므로 **상대 피 1장**을 B에게서 가져온다 (R09). B 피가 0장이면 가져올 피 없음.
- 더미 뒤집기 → 일반 처리.

점수 계산 예 (판 종료 시 A가 이렇게 가졌다고 가정)

| 영역 | A 획득 | 점수 |
|---|---|---|
| 광 | 1광, 3광, 8광 (비광 제외 3광) | 3 |
| 띠 | 1띠, 2띠, 3띠 (홍단) | 3 (띠 5장 미만이라 장수 점수 0) |
| 피 | 10장 | 1 |
| 합계 | | **7점 → 스톱 가능** |

- B 획득이 광 0장, 피 4장이면 광박(×2), 피박(×2) 적용.
- A가 스톱: 최종 점수 = 7 × 2 × 2 = **28점** (게임 내 점수, 환전 없음).
- A가 고를 1번 부르고 다음에 점수가 8점이 되어 스톱하면: (8 + 1) × 배수 = 9 × 배수 (3고 미만이라 고 배수 없음).
- A가 3고에서 스톱하면 (기본 + 3) × 2, 4고는 (기본 + 4) × 4 (R02 기본값 기준).

## 9. 매직 기능 후보 아이디어

> **원칙**: 매직은 "기존 고스톱 위에 얹는 켜고 끌 수 있는 확장"이다.
> - 매직을 끄면 1~8절의 기본 규칙 그대로 동작한다.
> - 매직이 바꾸는 값은 별도 효과로 분리 기록하고, 기본 점수 계산식(5.1~5.6)을 직접 고치지 않는다.
> - 아래 목록은 **후보일 뿐 설계 확정이 아니다**. 사용자가 고르면 game-designer가 balance.md에서 수치를 잡는다.
> - 확률형 유료 뽑기, 현금 가치 아이템, 환전은 금지(사행성).

### A. 매직 카드/아이템 (판 중간에 쓰는 특수 효과)

| 후보 | 한 줄 설명 | 밸런스 우려 |

## 10. 구현 메모 (developer 참고)

- 상태 기계: `DEAL → (총통 검사) → TURN[선택 H → 뒤집기 D → 정산 → 고/스톱] → END → 정산 → 다음 판`.
- 카드/바닥 구조: 월별 맵 `floor[month] = [cards]`로 두면 n 조회가 단순하다. 뻑 상태는 `floor[month].length === 3` 으로 판단 가능하다.
- 점수 함수는 `score(획득패, 옵션) → { base, details }` 순수 함수로 만들어 매 턴 재계산한다.
- 모든 선택 규칙(R01~R22)은 `ruleOptions` 객체 하나로 주입해, 규칙 확정 후 기본값만 바꾸면 되게 한다.
- 매직은 `magic.enabled=false`일 때 훅이 호출되지 않게 만들어 기본 규칙과 완전히 분리한다.
