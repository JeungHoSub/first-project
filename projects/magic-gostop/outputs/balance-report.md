# 엽전·아이템 밸런스 측정 (2026-11-24)

방법: 엔진 + 아이템 실제 코드로 자동 대국. 내 자리는 '보통' AI가 사람 대신 둔다(실제 사람보다 약간 약하거나 비슷). 초보·중수방 각 400판, 고수방 100판. 아이템은 "없음 / 전부 C 등급 / 전부 SS 등급"으로 비교.

## 한도 없을 때 (이전)
| 아이템 | 초보방 판당 | 중수방 판당 | 고수방 판당 |
|---|---|---|---|
| 없음 | +2,274 (승 65%) | −2,364 (승 55%) | −29,040 (승 53%) |
| 전부 C | +4,414 (73%) | +11,788 (64%) | −3,708 (52%) |
| 전부 SS | +7,811 (81%) | **+29,554** (63%) | **+46,061** (59%) |

- 아이템이 승률을 조금 올리지만, **큰 판(상위 10%)이 판당 5만~10만 엽전**을 몰고 와 평균이 크게 흔들림. SS면 중수방에서 한 시간(약 20판)에 60만 엽전 → 경제가 무너짐.
- 반대로 아이템 없이 고수방은 한 번 크게 지면 수만~수십만 엽전을 잃음.

## 적용: 한 판 한도 50점 (이겨도 져도)
| 아이템 | 초보방 판당 | 중수방 판당 | 고수방 판당 |
|---|---|---|---|
| 없음 | +488 | +765 | +581 |
| 전부 C | +1,296 | +3,457 | +10,635 |
| 전부 SS | +2,093 | +5,663 | +11,466 |

- 아이템 없으면 거의 본전, 좋은 아이템일수록 꾸준히 조금 더 범 → 모으는 재미는 남고 폭주는 없음.
- 실제 맞고 앱들의 "1판 한도"와 같은 방식. 결과 화면에 "→ 한도 50점"으로 표시, 규칙 화면에도 적음.

## 다음에 볼 것
- 사람이 직접 하면 봇보다 고를 덜/더 부르므로 실제 테스터 데이터로 다시 확인(비공개 테스트 때).
- 아이템 등급별 승률 차이(없음 65% → SS 79~81%)는 적당. 더 줄이려면 balance.ts의 확률표를 낮춤.
- 측정 스크립트는 다음에 다시 돌릴 수 있게 유지(세션 스크래치 → 필요하면 저장소로).
