# 스토어 등록 문구 초안 (Google Play / App Store)

## 기본
- **앱 이름**: 매직고스톱
- **짧은 설명(80자 이내)**: 한국 화투 맞고에 마법 아이템을! 35종 아이템을 모으고 AI와 한판 승부.
- **카테고리**: 게임 > 카드
- **표기**: 확률형 아이템 포함 · 현금 결제 없음 · 가상머니는 현금 가치 없음

## 상세 설명
진짜 한국 화투 그림으로 즐기는 1:1 맞고, 매직고스톱입니다.

■ 정통 맞고 규칙
뻑, 쪽, 따닥, 싹쓸이, 흔들기·폭탄, 총통, 피박·광박·멍따, 국진 선택, 나가리 이월까지 실제 규칙 그대로.

■ 마법 아이템 35종
주문 카드·부적·수호 정령·판 이벤트권·마법 도구·꾸미기. 등급은 F부터 SSS+까지.
천리안으로 상대 패를 엿보고, 구미호로 피를 홀려 오고, 땅울림으로 판을 뒤흔드세요.

■ 쉬움·보통·어려움 AI
상대 AI도 아이템을 장착합니다. 패는 항상 무작위, AI는 보이는 정보만 씁니다.

■ 국악과 함께
굿거리 장단 위의 대금·가야금 배경음악, 옻칠과 금박으로 꾸민 한국적인 화면.

■ 안심하고 즐기세요
현금 결제가 없고, 엽전(가상머니)과 아이템은 현금으로 바꿀 수 없습니다. 뽑기 확률은 앱 안에 모두 공개되어 있습니다.

## 스크린샷 계획 (폰 세로)
1. 처음 화면 (수묵 산수·보름달) 2. 대국 장면 (뻑/쪽 연출) 3. 뽑기 SSS+ 연출 4. 아이템 도감 5. 아이템 장착 화면

## 설문 답변 초안 (실제 제출은 본인이 앱 동작을 확인한 뒤)
- **데이터 보안**: 수집 데이터 없음 / 공유 없음 / 전송 시 암호화 해당 없음(전송 없음) / 데이터 삭제 = 앱 삭제
- **콘텐츠 등급(IARC)**: 도박 시뮬레이션 있음(현금 베팅·환전 없음), 폭력·선정성 없음, 사용자 간 소통 없음, 디지털 상품 구매 없음, 무작위 아이템 있음(가상머니로만)
- **타깃 연령**: 18세 이상
- **Apple 심사 노트**: "현금 결제와 환전 기능이 없습니다. 가상머니는 게임 승리로만 얻고 현금 가치가 없습니다. 무작위 아이템 확률은 구매 전 화면에 공개됩니다."
