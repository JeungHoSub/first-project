# 매직고스톱 출시 전 개선 점검 (2026-11-24)

현재 화면(휴대폰 크기)을 직접 찍어 보고, 코드와 지금까지의 작업 기록을 바탕으로 정리했다.
우선순위: 🔴 출시 전 꼭 · 🟠 출시 전 권장 · 🟢 출시 후

## 1. 수익 구조 — 가장 중요

| | 내용 |
|---|---|
| ✅ **금화 판매 = 엽전 판매가 되는 구조** (11-24 해결: 금화 무료 전용, monetization.md) | 금화 상점에서 **금화 → 엽전**으로 바꿀 수 있다. 금화를 현금으로 팔면 **판돈(엽전)을 돈으로 사는 것**이 되어 웹보드게임 규제(월 결제 한도, 본인 확인, 손실 한도 등)를 정면으로 받는다. 분해 → 엽전, 아이템 → 추가 엽전도 같은 길이다. |
| 해결 방향 | **돈으로 사는 것과 판돈을 완전히 끊는다.** 유료로는 "판에 영향 없는 것"만 판다: 광고 제거, 꾸미기(판·패 뒷면·동료 옷), 동료 캐릭터, 시즌 꾸미기 패스. 금화는 유료 전용 재화로 하고 금화→엽전 교환은 없앤다(또는 금화를 아예 무료 재화로만 둔다). |
| 🟠 보상형 광고 | "광고 보고 엽전 받기"(하루 몇 번 제한), 엽전이 바닥났을 때 "광고 보고 다시 채우기". 맞고 앱들의 주 수입원이고 규제 부담이 적다. 판 중간 전면 광고는 넣지 않는다(이탈 원인). |
| 🟠 파산 구제 | 엽전이 0이 되면 막힌다. 하루 1번 무료 구제금 + 광고 구제금이 필요하다. |
| 🟢 유료 상품 순서 | ① 광고 제거(1회 구매) → ② 꾸미기 묶음 → ③ 꾸미기 시즌 패스. 확률형(뽑기권) 유료 판매는 법률 확인 뒤 마지막. |

## 2. 처음 하는 사람 경험

| | 내용 |
|---|---|
| 🔴 튜토리얼 없음 | 맞고를 모르는 사람, 아이템·주문 카드를 처음 보는 사람이 막힌다. 첫 판에 손가락 안내 3~4단계(패 내기 → 먹기 → 고/스톱 → 주문 카드) 필요. |
| 🟠 출석 보상 | 7일 출석판(엽전 → 은화 → 7일째 뽑기권). 다시 들어올 이유. |
| 🟠 첫 판 쉬운 승리 | 첫 판은 봇이 살살 해서 "이기는 맛"부터. |

## 3. 화면·디자인

| | 내용 |
|---|---|
| 🟠 첫 화면 아래가 비어 있음 | 상점·동료 줄 아래로 휴대폰 화면 1/5 정도가 빈다. 출석/미션 알림 띠나 "오늘의 보상"을 두거나 전체를 아래로 내려 균형을 맞춘다. |
| 🟠 첫 화면 양옆 회색 원 | 달·해 장식이 흐릿한 회색 원으로만 보여 "빈칸"처럼 보인다. 그림으로 바꾸거나 뺀다. |
| 🟠 판 화면 | 바닥 패 사이 빈 공간이 크고 위치가 들쭉날쭉. 손패 아래쪽이 화면 끝에 잘린다. 먹은 패 칸(광·열끗·띠·피)이 작아 잘 안 보인다. 상위 앱처럼 "바닥은 월별로 가지런히, 손패는 한 줄 꽉 차게". |
| 🟠 결과 화면·숫자 연출 | 엽전이 올라가는 카운트업, 큰 승리 때 금빛 연출 강화. |
| 🟢 동료 캐릭터 | 6명 그림이 들어갔지만 표정(이길 때/질 때) 변화가 없다. 표정 2~3개씩 추가하면 생동감이 크게 오른다. |

## 4. 소리

| | 내용 |
|---|---|
| 🟠 실제 폰에서 들어 보기 | 효과음은 전부 코드로 합성했고 저는 직접 들을 수 없다. **실기기에서 한 번 쭉 들어 보고** 거슬리는 것만 알려 주시면 된다. 필요하면 일부를 실제 녹음 효과음(무료 라이선스)으로 바꾼다. |
| 🟢 음량 조절 | 지금은 켜기/끄기뿐. 배경음악·효과음·목소리 각각 크기 조절 막대. |

## 5. 앱으로서 필요한 것 (지금 없음)

| | 내용 |
|---|---|
| ✅ 안드로이드 뒤로 가기 버튼 (11-24 완료) | 처리가 없어 판 중에 누르면 앱이 바로 꺼질 수 있다. 창 닫기 → 홈 → "종료할까요?" 순서로. |
| ✅ 저장 데이터 보호 — 백업 코드 (11-24 완료, 클라우드 저장은 계정 연결 뒤) | 엽전·아이템이 폰 안에만 저장된다. 앱을 지우거나 폰을 바꾸면 전부 사라진다. 최소한 "백업 코드" 또는 구글 로그인 클라우드 저장. 결제를 붙이면 필수. |
| ✅ 화면 꺼짐 방지·화면 방향 고정·노치 여백 (11-24 완료) | 판 중 화면이 꺼지지 않게, 세로 고정. |
| 🟠 저사양 폰 성능 | 동전·노리개의 빛 효과(SVG 필터)와 연출이 많아 오래된 폰에서 버벅일 수 있다. "가벼운 연출" 설정 또는 자동 감지. |
| 🟠 온라인 서버 | 아직 Render 주소를 못 받아 실제 연결 전. 무료 서버는 15분 뒤 잠들어 첫 연결이 최대 1분 걸린다. 출시 때는 월 7달러 상시 서버 권장. |
| 🟢 랭킹·전적 | 온라인 승률·연승 기록, 주간 랭킹. |

## 6. 게임성·밸런스

| | 내용 |
|---|---|
| 🟠 엽전 흐름 점검 | 미션·분해·윷·아이템 추가 엽전 등 들어오는 곳이 많아졌다. 100판 자동 대국으로 "한 시간 하면 얼마 버는지"를 재고, 방 입장 금액(3,000/15,000/60,000)과 맞춘다. |
| 🟠 아이템이 너무 세지 않은지 | 패시브가 겹치면 봇전이 너무 쉬워질 수 있다. 자동 대국으로 승률을 재서 조정. |
| 🟢 봇 성격 | 동료/상대마다 말투·플레이 성향(공격형·수비형) 차이. |

## 제안하는 순서

1. **수익 구조 정리**(금화→엽전 끊기, 광고 자리 마련) — 나중에 바꾸면 이미 쌓인 재화 처리가 골치 아프다.
2. **앱 필수**(뒤로 가기, 저장 백업, 화면 꺼짐 방지).
3. **튜토리얼 + 출석 + 파산 구제.**
4. **판 화면·첫 화면 다듬기.**
5. 엽전 흐름·아이템 밸런스 자동 점검.
6. 실기기로 소리·성능 확인 → 비공개 테스트 시작.
