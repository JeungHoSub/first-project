# 상위 맞고 앱 벤치마킹 메모 (2026-11-18)

대상: 피망 뉴맞고(네오위즈), 한게임 신맞고(NHN) 등 국내 상위 맞고 앱.
검색으로 확인한 범위가 좁아(스토어 소개·옛 보도자료), 아래는 확인된 사실과 일반적인 화면 관례를 나눠 적는다.

## 확인된 것
- 피망 뉴맞고: 실시간 대전, 원조 맞고 룰, **패 속도 조절**, **화투패 스킨(골드·우드 등)**
- 한게임 신맞고: 개편 때 **효과 음성(목소리)**, 미션 추가 / 맞고 개편 때 **점수·피 자동 집계 화면**, 이벤트 때 캐릭터 그래픽 연출

## 매직고스톱에 반영한 것
| 항목 | 상위 앱 관례 | 반영 |
|---|---|---|
| 효과 음성 | 고·스톱·뻑·쪽·따닥·싹쓸이를 목소리로 | 기기 한국어 음성(TTS)으로 한 수에 가장 중요한 1개만. 설정에서 끄기 가능 |
| 패 속도 | 보통/빠르게 | "소리와 설정"에 패 속도 보통·빠르게(0.6배) |
| 판 | 화면을 꽉 채운 담요, 가지런한 바닥 | 타원 → 꽉 찬 둥근 사각 담요, 바닥 패 기울기·흔들림 제거, 바닥 패 크게 |
| 섞기 소리 | 판 시작 때 촤라락 | 새 판에 섞는 소리 + 탁탁 정리 |
| 점수 자동 집계 | 광/열끗/띠/피 칸별 장수·점수 | 이미 있음 (유지) |
| 패 스킨 | 여러 뒷면 | 꾸미기 아이템으로 이미 있음 |

## 다음 후보
- 효과 음성을 실제 성우 녹음 파일로 교체(정식 출시 전, 저작권 확인 필요)
- 결과 화면을 "점수 내역 → 엽전 정산" 두 단계로 더 크게
