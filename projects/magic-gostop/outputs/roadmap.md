# 매직고스톱 로드맵 (초안 v0.1)

> 작성: planner / 2026-11-12
> 전제: 웹, AI 1인용, 2인 맞고, 매직 카드(A) 먼저. 사용자 답변에 따라 조정.
> 목표: MVP를 1~2주 안에 돌아가게. 기간은 대략 가늠치.

| 단계 | 내용 | 담당 | 기간(대략) |
|---|---|---|---|
| 0 | 기획 | planner | 완료(초안) |
| 1 | 규칙 설계 | game-designer | 1~2일 |
| 2 | 엔진 | developer | 2~3일 |
| 3 | 화면 | developer | 2~3일 |
| 4 | AI 상대 | developer | 1~2일 |
| 5 | 매직 | game-designer -> developer | 2~3일 |
| 6 | 검수/배포 | reviewer -> 사용자 | 1~2일 |

단계 3~4는 일부 겹쳐 진행할 수 있다.

## 0단계 기획 (planner)
- 할 일: spec.md, roadmap.md 작성, 확인 필요 항목 정리
- 완료 기준: 사용자가 미결정 질문(spec 11절)에 답함, brief "결정됨"에 반영

## 1단계 규칙 설계 (game-designer)
- 할 일: 기본 고스톱 규칙 정리(`rules.md`), 점수 계산표, 특수 상황 목록, 규칙 불명확 지점은 선택지로 정리
- 완료 기준: rules.md만 보고 개발자가 엔진을 만들 수 있음. 지역별 규칙 차이(예: 점수 기준)는 "기본값 + 옵션"으로 확정
- 산출물: `outputs/rules.md`

## 2단계 엔진 (developer)
- 할 일: 패 분배, 매칭, 특수 상황, 점수 계산, 고/스톱을 UI와 분리한 순수 로직으로. 셔플 시드 지원. 이벤트 훅 자리(비어 있어도 됨) 마련
- 완료 기준: 규칙 케이스별 자동 테스트 통과, 같은 시드면 같은 결과, 콘솔/테스트로 한 판 끝까지 진행 가능
- 산출물: `outputs/` 또는 코드 폴더 + 테스트, log.md 인계

## 3단계 화면 (developer)
- 할 일: 시작/대전/결과 화면, 카드 이동 표시, 점수·고/스톱 UI, 도움말, "현금 가치 없음" 문구
- 완료 기준: 브라우저에서 사람이 한 판을 처음부터 끝까지 플레이 가능 (상대는 임시 AI), 모바일 폭에서도 깨지지 않음

## 4단계 AI 상대 (developer)
- 할 일: 규칙 기반 AI(쉬운 난이도), 패 선택 우선순위, 고/스톱 판단
- 완료 기준: AI가 반칙 없이 100판 자동 대전 완주, 사람이 해볼 때 너무 바보/너무 강하지 않음

## 5단계 매직 (game-designer -> developer)
- game-designer: 매직 카드 3~4종 확정(효과, 발동 시점, 사용 제한, 점수 영향 밸런스)
- developer: 매직 층 구현(이벤트 훅/수정자), ON/OFF 토글, 카드 사용 UI, AI의 매직 사용
- 완료 기준: 매직 OFF일 때 같은 시드 결과가 기본 엔진과 완전히 동일(자동 테스트), 카드별 효과 테스트 통과, 매직 ON 100판 자동 대전 무오류

## 6단계 검수/배포 (reviewer -> 사용자)
- reviewer: 규칙 일관성, 점수 계산 검증, 버그, 사행성 문구·구조 점검, 화투 이미지 출처 확인(`copyright-check` 스킬 참고 가능)
- 배포: 정적 호스팅에 올려 공유 링크 생성 (비용 0원 목표)
- 총괄: `review/QUEUE.md`에 검토 요청(`request-review`) -> 사용자 검토
- 완료 기준: 치명 버그 0, 검수 보고서 작성, 사용자가 플레이해 보고 피드백 가능한 상태

## 이후 (MVP 통과 후, 사용자 피드백 기준으로 선택)

- 모바일 앱 포장 (등급 심사 조사 선행), 온라인 멀티
- B 캐릭터 스킬, D 성장·수집
- 필요 시 `skill-scout`로 게임 엔진/프레임워크 관련 스킬 탐색

## 위험 메모
| 위험 | 대응 |
|---|---|
| 규칙 해석 차이로 엔진 재작업 | 1단계에서 rules.md 확정 후 착수, 모호한 건 사용자에게 질문 |
| 매직이 밸런스를 깨뜨림 | 사용 횟수 제한, AI 자동 대전으로 승률 점검 |
| 사행성 오해 | 점수만 사용, 결제/랭킹 보상 없음, 문구 표시, 앱 출시 전 등급 조사 |
| 일정 지연 | 매직 카드 수와 AI 난이도를 줄여 MVP 유지 |
