# 프로젝트: 매직고스톱

## 목표
- **기존 고스톱 규칙은 그대로** 두고, 그 위에 "매직"이라는 추가 기능을 얹은 게임
- 기본 고스톱만으로도 완성된 게임이어야 하고, 매직은 켜고 끌 수 있는 확장 요소로 설계

## 역할 분담
| 단계 | 담당 에이전트 | 하는 일 |
|---|---|---|
| 1 | planner | 컨셉·플랫폼·MVP 범위 |
| 2 | game-designer | 기본 고스톱 규칙 + 매직 카드/능력, 점수 밸런스 |
| 3 | developer | 게임 엔진(패 분배·매칭·점수 계산) → 화면 → AI 상대 |
| 4 | reviewer | 규칙 일관성·버그 점검 |

## 필요한 스킬
- 있음: handoff, request-review, style-guide
- 필요 시 skill-scout: 게임 엔진/프레임워크 선택에 따라 결정

## 위험
- 사행성: 현금·유료 판돈·환전 구조 금지. 앱스토어 등급 심사 기준 확인 필요.

## 결정됨 (2026-11-12)
- 매직 = 기존 고스톱 + 추가 기능

## 결정됨 (2026-11-16, 사용자: "추천안대로 진행")
- 플랫폼 웹(브라우저) 먼저 / 대전 AI 상대 1인용 먼저 / 기본 인원 2인 맞고
- 매직: 매직 카드 먼저(판당 1~2장 제한) → 이후 판 규칙 변형 → 캐릭터·성장
- MVP 매직 카드 4종: 엿보기·패 바꾸기·방패·바닥 정리
- 규칙: 피박 = 패자 피 1~5장 (2026-11-16 변경: 0장은 피박 아님) / 총통 = 10점 × 나가리 이월 / 멍따 = 승자 열끗 7장 이상 ×2 / 고 가산 +n, 3고 ×2·4고 ×4 / 자뻑 = 상대 피 2장
- 화투 그림 자체 제작 (2026-11-16 직접 그린 SVG 1차 버전 적용), 출시는 개인 공유용 웹
- 기술: TypeScript + Vite, 엔진·화면 분리
- 2026-11-16 추가: 최종 목표는 **앱**. 웹 화면으로 단계마다 미리보기 링크를 만들어 사용자가 직접 해 보고 다음 단계로 간다. 앱 포장 방식(웹 화면을 앱으로 감싸기 등)은 화면이 안정된 뒤 결정

## 개발 단계 (사용자 지정, 2026-11-16)
1. 기본적인 룰을 가진 고스톱 만들기 (엔진)
2. 사용자가 게임할 수 있게 하기 (화면 + AI 상대)
3. 위에서 정한 룰 적용하기 (뻑·따닥·쪽·싹쓸이·흔들기·폭탄·총통·박·국진 등)
4. 추가적인 내용 넣기 (매직)
5. (미정)

## 확인 필요 (아래는 결정 이전 기록)
1. 추가 기능의 종류 (여러 개 선택 가능, 이미 생각해 둔 게 있으면 그걸 우선):
   A) 매직 카드/아이템 — 판 중간에 쓰는 특수 효과 (패 바꾸기, 상대 패 1장 보기, 점수 2배 등)
   B) 캐릭터 스킬 — 캐릭터마다 고유 능력 1개
   C) 판 규칙 변형 — 판마다 랜덤 이벤트 (이번 판은 광 점수 2배 등)
   D) 성장 요소 — 레벨·수집·덱 꾸미기
2. 플랫폼: A) 웹(브라우저) 먼저 — 추천 B) 모바일 앱 C) PC
3. 대전 방식: A) AI 상대 1인용 먼저 — 추천 B) 온라인 멀티
