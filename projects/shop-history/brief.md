# 프로젝트: 이 자리 몇 번 망했나 (shop-history)

## 목표
- 상가 주소를 넣으면 **그 자리에 들어왔다 나간 가게의 역사**(업종·영업 기간·폐업 시점)를 보여준다.
- 1단계: 평택 시제품(글로우버거 자리로 검증) → 2단계: 평택·화성 상가 중개사 검증 → 3단계: 경기 남부 확대.
- 출처: money-ideas I-021 (`projects/money-ideas/outputs/I-021-revenue-build.md`)

## 가격 구조 (2026-11-24 사용자 결정)
- **기본은 구독**(상가 전문 공인중개사·창업 컨설턴트 대상, 무제한 조회·리포트 출력).
- **처음 몇 곳은 무료**(가입 시 무료 조회 N건).
- 가끔 쓰는 사람은 **충전식(크레딧 선불)**: 충전한 만큼 건당 차감.
- 숫자(무료 건수·충전 단가·구독료)는 중개사 검증 단계에서 확정. 가설: 무료 3건, 충전 1건 약 3,000원, 구독 월 2만~3만 원.

## 데이터
- 행정안전부 지방행정 인허가 데이터(195종, 공공데이터포털 API / LOCALDATA 파일): 소재지 주소·인허가일자·폐업일자·영업상태.
- 한계: 인허가가 필요한 업종만(음식점·카페·미용·학원 등). 신고 없는 소매는 빠짐 → 처음엔 "음식점·카페·미용·학원 자리" 전용이라고 표시.

## 담당 에이전트
- developer(데이터 수집·주소 묶기·웹페이지) → planner(가격·판매) → reviewer

## 제약 / 참고
- 개인정보: 상호·대표자는 보여주지 않고 업종·영업 기간만.
- 핵심 난제: 주소 정규화(지번/도로명, 층·호).
