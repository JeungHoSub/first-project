# 술게임 — 게임 규칙 (초안 v0.1)

작성: game-designer / 2026-11-12
기준: `spec.md`의 MVP 후보 5개. 일정이 빠듯하면 1·2·4번만 먼저 만들어도 된다(spec 2절).
카드 문구는 `content-missions.md`에 있다. 이 문서는 규칙과 화면 흐름만 다룬다.

---

## 0. 모든 게임 공통 규칙 (한 번만 읽으면 돼요)

| 항목 | 내용 |
|---|---|
| 폰 | 한 대만 돌려 써요. 지금 차례인 사람이 폰을 들어요. |
| 이름 | 시작할 때 2~10명 닉네임을 넣어요. 이 기기 안에서만 쓰고, 서버에는 안 보내요. |
| 모드 | 음주 모드 / 비음주 모드. 게임 중에도 바꿀 수 있어요. 한 테이블에 마시는 사람과 안 마시는 사람이 섞여 있어도 돼요. 카드는 같고, 벌칙 문구만 바뀌어요. |
| 패스 | 어떤 카드든 패스 가능, 벌칙·눈치 없음. 화면에 늘 "패스" 버튼이 있어요. |
| 한 모금의 뜻 | 입술을 적시는 정도도 OK. 음주 벌칙은 카드 한 장에 한 모금이 끝이에요. 여러 번 걸려도 한 번만 마셔요. |
| 쉬어가기 | 벌칙 카드를 10장 뽑을 때마다 "물 한 잔 마시고 가요" 화면이 한 번 떠요. 누가 몇 모금 마셨는지는 기록하지 않아요. |
| 안내 문구 | 시작 화면과 벌칙 화면에 항상 "마시기 싫으면 언제든 패스하거나 비음주 모드로 바꿀 수 있어요" 표시. 음주 후 운전 금지, 몸이 안 좋으면 바로 중단. |
| 성인 확인 | 처음 들어올 때 "만 19세 이상만 음주 모드를 쓸 수 있어요" 확인. 확인 안 하면 비음주 모드만 열려요. |
| 승패 | 벌칙은 "벌"이 아니라 "양념"이에요. 기분 상하는 분위기가 되면 누구나 "그만" 하고 게임을 끝낼 수 있어요. |
| 판정 | 앱은 사전도 심판도 아니에요. 애매하면 같이 있는 사람들이 다수결로 정해요(앱에 "인정 / 아쉬워" 버튼). |

### 공통 앱 화면 흐름 (개발자 참고)

1. 최초 진입: 이용 안내 + 성인 확인(1회). 못 넘기면 비음주 전용.
2. 플레이어 입력(2~10명, 새로고침해도 유지).
3. 모드 선택(음주 / 비음주). 기본값은 사용자 답변 대기(spec 11절 2번). 지금은 비음주 기본 가정.
4. 게임 선택(카드 5장 목록, 각 카드에 "몇 명 / 몇 분" 표시).
5. 게임 화면. 상단 고정: 모드 전환 토글, 소리/진동 토글, 나가기. 하단 고정: 패스 버튼과 안전 문구.
6. 결과 화면 -> "한 판 더" / "다른 게임".

공통 부품: 카드 덱(셔플, 중복 없이 소진 후 재셔플), 룰렛, 타이머. 5개 게임이 이 세 부품으로 돌아가요.

## 게임 1. 벌칙 룰렛

| 항목 | 내용 |
|---|---|
| 한 줄 | 룰렛이 사람을 찍고, 찍힌 사람이 벌칙 카드를 한 장 뽑아요. |
| 인원 / 시간 | 2~10명 / 한 번 돌리는 데 30초, 계속 이어서 해도 OK |
| 준비물 | 폰 하나. 앱 기능: 룰렛, 벌칙 카드 덱, 강도 필터 |

**1분 설명 (3문장)**
1. 돌리기 버튼을 누르면 룰렛이 돌아가서 한 사람의 이름에 멈춰요.
2. 걸린 사람은 벌칙 카드 한 장을 뽑아서 읽고 해요. 하기 싫으면 패스.
3. 끝나면 다시 돌려요. 그만하고 싶을 때가 끝이에요.

**진행 순서**
1. 시작 전 강도를 골라요: 가벼움 / 가벼움+중간(기본).
2. 아무나 "돌리기"를 눌러요(폰을 든 사람이 눌러야 하는 건 아니에요).
3. 룰렛이 멈추면 당첨자 이름이 크게 뜨고 진동이 울려요.
4. 벌칙 카드가 자동으로 한 장 열려요. 현재 모드에 맞는 문구가 보여요.
5. 당첨자가 "했어요" 또는 "패스"를 눌러요.
6. 2번으로 돌아가요.

**승패 / 벌칙**: 이기고 지는 건 없어요. 걸린 사람이 벌칙 카드 1장을 해요. 음주 모드는 한 모금 상한, 비음주 모드는 행동·말하기 문구.

**예외 상황**
| 상황 | 처리 |
|---|---|
| 같은 사람이 연속으로 걸림 | 4명 이상이면 "방금 걸린 사람 제외"가 기본 켜짐. 3명 이하는 꺼짐(제외하면 선택이 의미 없어져서). 설정에서 끌 수 있음 |
| 룰렛 도중 이름 추가·삭제 | 룰렛이 멈춘 뒤에만 가능. 도는 중에는 버튼 비활성 |
| 벌칙이 마음에 안 듦 | 패스(벌칙 없음) |
| 자리 비운 사람 | 이름 옆 "쉬는 중" 토글로 룰렛에서 제외 |

**음주 / 비음주 차이**: 카드는 같은 id. 문구만 바뀌어요. 룰렛 연출·사운드·진동은 똑같아요.

**앱 화면 흐름 메모**: 룰렛 화면(큰 돌리기 버튼) -> 당첨 모달(이름+진동) -> 벌칙 카드 모달(수행/패스 버튼 2개) -> 룰렛 화면. 10장마다 쉬어가기 모달. 룰렛 애니메이션은 2~3초, 결과는 시작 전에 미리 정해 두고 연출만(중간에 새로고침해도 중복 추첨 안 되게).

**밸런스·재미 포인트**
- 가장 단순해서 처음 보는 사람도 바로 시작해요. 첫 게임 추천용.
- 균등 확률이라 "운이 없네" 하는 웃음이 나오는데, 가중치는 일부러 안 넣었어요(spec 2절).
- 벌칙 강도를 낮게 시작해서 분위기 보며 올리는 구조가 재미 포인트.

## 게임 2. 미션 카드 뽑기

| 항목 | 내용 |
|---|---|
| 한 줄 | 카드를 뽑고 미션을 해내면 점수. 끝나고 점수가 제일 낮은 사람이 가벼운 벌칙. |
| 인원 / 시간 | 3~10명 / 10~15분 |
| 준비물 | 폰 하나. 앱 기능: 미션 카드 덱, 점수판, 인정 투표 버튼 |

**1분 설명 (3문장)**
1. 차례가 되면 카드를 뽑아서 미션을 수행해요.
2. 나머지 사람들이 "인정"하면 1점, 패스하거나 "아쉬워"가 많으면 0점이에요.
3. 정해진 라운드가 끝나면 점수가 제일 낮은 사람이 벌칙 카드를 한 장 뽑아요.

**진행 순서**
1. 라운드 수를 골라요: 2 / 3(기본) / 5라운드. 한 라운드 = 모든 사람이 카드 1장씩.
2. 첫 사람이 "카드 뽑기"를 눌러요. 미션이 크게 떠요. 카드엔 강도 표시가 있어요.
3. 읽은 사람이 수행하거나 "패스"를 눌러요.
4. 수행했다면 나머지 사람이 한 번에 "인정" 또는 "아쉬워"를 외쳐요. 앱에서는 대표 한 명이 다수결 결과를 눌러요.
5. 인정이면 +1점. 아쉬워나 패스면 0점(패스에 감점 없음).
6. 폰을 다음 사람에게 넘겨요. 모든 라운드가 끝날 때까지 반복.
7. 결과 화면: 1등 "오늘의 분위기 메이커" 표시, 꼴찌는 벌칙 카드 1장.

**승패 / 벌칙**
| 결과 | 처리 |
|---|---|
| 최고점 | 칭호만 받아요(상품 없음, 돈 오가는 구조 없음) |
| 최저점 | 벌칙 카드 1장(가벼움 단계). 패스 가능 |
| 동점 최저 | 가위바위보 대신 앱이 "랜덤 룰렛"으로 한 명을 정함(룰렛 부품 재사용). 또는 전원 패스로 끝내도 됨 |
| 전원 동점 | 벌칙 없이 "다 같이 박수(잔이 있으면 가볍게 건배만)" 화면 |

**예외 상황**
| 상황 | 처리 |
|---|---|
| 미션을 이해 못 함 | 카드 우측 아래 "다른 카드" 버튼으로 1회 교체(교체는 점수 영향 없음) |
| 인정 투표가 갈림 | 수행한 본인은 투표 제외, 동수면 인정 |
| 사람이 중간에 빠짐 | 이름을 "쉬는 중"으로 바꾸면 남은 라운드에서 제외, 점수는 최저점 계산에서 빠짐 |
| 미션이 위험하거나 불편함 | 누구든 "패스" 가능. 앱은 이유를 묻지 않음 |

**음주 / 비음주 차이**: 미션 본문과 점수 규칙은 똑같아요. 달라지는 건 마지막 최저점 벌칙 문구뿐. 음주 모드에서도 미션 중에 마시는 건 없어요(마시기 중심 게임이 되지 않게).

**앱 화면 흐름 메모**: 라운드 선택 -> (반복) 차례 안내 화면(이름 크게) -> 카드 화면(패스 / 다른 카드 / 완료) -> 인정 투표 화면(인정 / 아쉬워) -> 점수 갱신 토스트 -> 다음 사람 -> 결과 화면 -> 벌칙 카드.

**밸런스·재미 포인트**
- 점수는 1점 고정이라 계산이 쉬워요. 미션 강도가 높다고 점수를 더 주지 않아요(어려운 걸 고르게 압박하는 구조 방지).
- 패스가 감점이 아니라서 "안 하면 손해"가 없어요. 대신 해낸 사람만 칭호를 얻어서 해볼 만하게 만들었어요.
- 카드에 따라 "다 같이 하는 미션"이 섞여 있어 분위기가 올라가요.

## 게임 3. 진실 혹은 도전

| 항목 | 내용 |
|---|---|
| 한 줄 | 지목당한 사람이 진실(질문에 답하기)과 도전(미션) 중 하나를 골라요. |
| 인원 / 시간 | 3~10명 / 10~20분. 대화 중심이라 비음주 모드와 잘 맞아요. |
| 준비물 | 폰 하나. 앱 기능: 진실 덱, 도전 덱, 선택 버튼, 용기 점수판 |

**1분 설명 (3문장)**
1. 폰을 든 사람이 다른 사람을 지목하면, 지목당한 사람이 "진실"이나 "도전"을 골라요.
2. 진실은 질문에 대답하고, 도전은 미션을 해요. 하면 용기 점수 +1, 패스는 0점이고 벌칙 없어요.
3. 모두가 한 바퀴 돌 때까지 하다가, 용기 점수가 제일 높은 사람이 오늘의 용감한 사람이 돼요.

**진행 순서**
1. 첫 사람이 폰을 들고 다른 한 명을 지목해요(앱에서 이름 탭).
2. 지목당한 사람이 "진실" 또는 "도전" 버튼을 골라요. 폰은 지목당한 사람 쪽으로 돌려줘요.
3. 카드가 열려요. 읽고 대답하거나 수행해요. 너무 곤란하면 "패스".
4. 완료하면 "했어요" 버튼, 용기 점수 +1.
5. 지목당했던 사람이 다음 폰 주인이 돼서 다음 사람을 지목해요.
6. 한 사람당 2번씩(기본) 지목당하면 끝. 같은 사람이 연속 2번 지목되지 않게 앱이 이름을 흐리게 표시해요.

**승패 / 벌칙**: 벌칙이 없는 게임이에요. 용기 점수 1등이 "용감한 사람" 칭호를 받고 다음 게임의 시작 순서를 정해요.

**예외 상황**
| 상황 | 처리 |
|---|---|
| 질문이 너무 사적임 | 패스. 질문 카드는 본인이 아닌 다른 사람이 읽지 않고, 지목당한 본인만 화면을 봐요(폰을 돌려받음) |
| 같은 사람이 계속 진실만 고름 | 제약 없음. 대신 "연속 3번 진실이면 다음엔 도전 카드가 나올 수 있어요" 안내 문구(강제 아님, 패스 가능) |
| 대답이 거짓말 같음 | 확인할 방법이 없어요. 의심은 농담으로만, 추궁 금지. 앱 안내 문구에 적음 |
| 미성년자 혼합 | 음주 모드 잠금 상태이므로 비음주 문구만 노출 |

**음주 / 비음주 차이**: 카드 본문은 같아요. 음주 모드에서는 대답·수행 대신 "한 모금 마시고 넘기기"를 선택지로 둘 수 있어요(선택일 뿐, 순수 패스도 벌칙 없음). 비음주 모드의 같은 자리에는 "물 한 모금 + 다음 사람 지목" 같은 가벼운 대체가 떠요.

**앱 화면 흐름 메모**: 지목 화면(이름 목록) -> 선택 화면(진실/도전 두 버튼) -> 카드 화면(본인 전용 안내, 완료/패스) -> 점수 갱신 -> 지목 화면. 결과: 용기 점수 막대 그래프.

**밸런스·재미 포인트**
- 도전 카드는 "웃기지만 안전한 것"만, 진실 질문은 "취향·에피소드" 위주로 모욕·성적·직장 사생활 질문을 뺐어요.
- 패스 무벌칙이라 대신 해냈을 때 보상(점수, 칭호)이 눈에 띄게.
- 진실 질문이 대화 불씨가 돼서 어색한 첫 자리에서 특히 좋아요.

## 게임 4. 폭탄 돌리기

| 항목 | 내용 |
|---|---|
| 한 줄 | 폰이 "폭탄"이에요. 터지기 전에 주제 단어를 말하고 옆 사람에게 넘겨요. |
| 인원 / 시간 | 3~10명 / 판당 1~2분 |
| 준비물 | 폰 하나(소리·진동 권장, 없어도 화면 연출로 진행 가능). 앱 기능: 숨김 랜덤 타이머, 주제 카드, 벌칙 카드 |

**1분 설명 (3문장)**
1. 화면에 주제가 뜨면, 폰을 든 사람이 주제에 맞는 단어를 하나 말하고 왼쪽 사람에게 폰을 건네요.
2. 몇 초 뒤에 폭탄이 터지는데(언제 터질지는 앱만 알아요), 터질 때 폰을 들고 있던 사람이 벌칙 카드를 뽑아요.
3. 단어가 안 떠오르거나 먼저 나온 단어를 말하면 그 자리에서 "아쉬워" 판정, 다음 사람에게 넘어가요(폭탄은 계속 돌아가요).

**진행 순서**
1. 시작할 사람이 "폭탄 켜기"를 눌러요. 주제 카드가 뜨고 심지 불꽃 애니메이션이 시작돼요.
2. 폰을 든 사람이 주제 단어를 말해요(예: 주제 "라면 재료" -> "계란").
3. 말하자마자 **던지지 말고 손에서 손으로** 왼쪽 사람에게 건네요.
4. 받은 사람도 겹치지 않는 단어를 말하고 또 왼쪽으로.
5. 폭탄이 터지면 진동과 큰 화면 연출. 들고 있던 사람이 벌칙 카드를 한 장 뽑아요.
6. 벌칙 후 터진 사람이 다음 판의 시작 사람이 돼요.

**승패 / 벌칙**: 터질 때 들고 있던 사람이 벌칙 카드 1장(가벼움~중간). 판 수 제한은 없어요.

**타이머 규칙 (숨김)**
| 항목 | 값 | 이유 |
|---|---|---|
| 최소 | 8초 | 시작하자마자 터지면 재미없고 억울해서 |
| 최대 | 35초 | 너무 길면 지루해서 |
| 분포 | 8~35초 균등 | 초안값. 실제 플레이 테스트로 조정 |
| 표시 | 남은 시간 숨김, 불꽃 속도만 점점 빨라짐 | 눈치 게임 유지 |

**예외 상황**
| 상황 | 처리 |
|---|---|
| 폭탄이 터지는 순간이 애매함(폰이 손 사이에 있음) | 폰을 쥐고 있던 사람 기준. 서로 웃고 넘어가는 걸 권장 |
| 주제 단어가 기억 안 남 | 3초 내에 말 못하면 "아쉬워"로 간주하지만 벌칙은 폭탄이 터질 때까지 보류. 즉 단어 실패 자체에 벌칙 없음 |
| 폰 파손 위험 | 던지기·뺏기 금지. 앱 시작 화면에 "건네주세요, 던지지 마세요" 안내 |
| 소리를 못 쓰는 자리 | 소리 끄기 가능. 진동과 화면 플래시로 대체 |
| 폰을 떨어뜨림 | 타이머 일시정지 버튼(앱 상단). 누르면 시간은 이어서 진행(리셋 안 함) |
| 한 사람이 연속 3판 터짐 | 4번째 판은 앱이 "이번 판은 시작 사람을 바꿔요" 추천(그냥 눌러 넘겨도 됨) |

**음주 / 비음주 차이**: 터진 뒤 벌칙 카드 문구만 달라요. 비음주 모드에서는 "행동·말하기" 중심이 나와요.

**앱 화면 흐름 메모**: 시작 화면(주제 선택/랜덤, 안내) -> 폭탄 화면(주제 크게, 불꽃, 일시정지) -> 폭발 화면(터진 사람 이름 선택 또는 "다음 사람" 버튼 방식 — developer와 협의: 앱은 누가 들었는지 모르니 터진 뒤 이름을 탭하는 방식 추천) -> 벌칙 카드 -> 다음 판.

**밸런스·재미 포인트**
- 가장 "폰 하나" 형태에 맞는 게임이에요. 주제를 붙여서 그냥 폭탄보다 한 단계 더 웃겨요.
- 완전 랜덤이라 앞에서 터지거나 뒤에서 터지는 불공평은 "운"으로 받아들일 수 있게 8초 하한만 뒀어요.
- 단어 실패에 벌칙을 안 줘서 압박이 심하지 않아요.

## 게임 5. 초성/주제 게임

| 항목 | 내용 |
|---|---|
| 한 줄 | 제시된 초성이나 주제에 맞는 단어를 차례로 5초 안에 말해요. |
| 인원 / 시간 | 2~10명 / 라운드당 1~2분 |
| 준비물 | 폰 하나. 앱 기능: 랜덤 제시어, 턴 타이머, 벌칙 카드 |

**1분 설명 (3문장)**
1. 화면에 "ㅅㄱ" 같은 초성이나 "라면 재료" 같은 주제가 떠요.
2. 한 명씩 돌아가며 5초 안에 맞는 단어를 하나 말해요(이미 나온 단어는 안 돼요).
3. 못 말하거나 겹치면 그 라운드는 끝, 그 사람이 벌칙 카드를 한 장 뽑아요.

**진행 순서**
1. "제시어 뽑기"를 눌러요. 초성 또는 주제가 크게 떠요(설정에서 둘 중 하나 또는 섞기).
2. 첫 사람이 "시작"을 누르면 5초 타이머가 돌아요(3/5/7초 설정).
3. 단어를 말하면 "다음" 버튼을 눌러요(폰은 돌리지 않고 테이블에 두어도 돼요. 누구든 눌러요).
4. 다음 사람 차례, 타이머 리셋.
5. 시간이 끝나면 삐 소리와 진동. 그 사람이 벌칙 카드를 한 장 뽑아요.
6. 이긴 사람은 없고, 다음 제시어로 새 라운드. 벌칙을 한 사람이 새 라운드를 시작해요.

**승패 / 벌칙**: 시간 초과나 중복 단어를 말한 사람이 벌칙 카드 1장(가벼움). 한 라운드에 벌칙은 한 번만.

**예외 상황**
| 상황 | 처리 |
|---|---|
| 단어가 맞는지 애매함(신조어, 줄임말) | 다수결 "인정/아쉬워". 사전 확인 안 함. 동수면 인정 |
| 중복 판정 | 같은 단어를 먼저 말한 사람이 이미 있으면 중복. 헷갈리면 인정 |
| 제시어가 너무 어려움 | "다른 제시어" 버튼으로 라운드당 1회 교체 가능 |
| 2명만 있을 때 | 그대로 진행 가능. 단 5라운드까지만 추천 안내 |
| 타이머가 너무 빡빡함 | 7초로 올리는 "느긋하게" 모드 |
| 소리 못 씀 | 진동과 화면 색 변화로 대체 |

**음주 / 비음주 차이**: 제시어와 규칙은 같아요. 벌칙 카드 문구만 달라요. 다른 점 하나: 음주 모드에서도 "한 모금 상한 1회"는 라운드마다 적용해요. 연속 라운드에서 같은 사람이 계속 걸려도 쉬어가기 알림(10장마다)이 뜹니다.

**앱 화면 흐름 메모**: 모드 설정(초성/주제/섞기, 시간) -> 제시어 화면(큰 글씨, 시작 버튼) -> 타이머 화면(원형 게이지, 다음 버튼) -> 타임오버 화면 -> 벌칙 카드. 제시어 풀은 JSON, 초성은 흔한 조합만 넣어 단어가 안 나오는 사고 최소화.

**밸런스·재미 포인트**
- 어른도 헷갈리게 어려운 초성이 아니라 "아는 단어가 3~4개는 나오는" 조합만 골랐어요.
- 5초 기본값은 "급한 압박"과 "생각할 시간"의 중간. 플레이 테스트로 조정 필요.
- 준비물이 없고 규칙이 쉬워서 이동 중, 모임 대기 시간 등 짧은 틈에 좋아요.

## 예시 판 (게임 2: 미션 카드 뽑기, 4명 3라운드, 비음주 모드)

참가자: 민지, 도윤, 서아, 하준. 비음주 모드(음료는 각자).

1. 민지가 폰을 들고 라운드 3을 골라요.
2. 라운드 1, 민지 차례. 카드: "오른쪽 사람의 장점을 한 가지 말하기". 오른쪽은 도윤. 민지가 "도윤이는 약속 시간에 먼저 와 있어서 믿음직해"라고 말해요. 나머지 3명이 "인정!" -> 민지 +1점.
3. 도윤 차례. 카드: "말 없이 몸짓만으로 '라면 끓이기'를 표현하기". 도윤이 어려워서 "패스" -> 0점(벌칙 없음).
4. 서아 차례. 카드: "10초 안에 과일 5개 말하기". 해냈어요. 인정 -> +1점.
5. 하준 차례. 카드: "오늘 하루를 영화 제목으로 말하기". "퇴근 후 치킨". 반응이 갈렸는데 2대 1로 인정이 많아서 +1점.
6. 라운드 2, 3도 똑같이 반복. 마지막 점수: 민지 3, 서아 3, 하준 2, 도윤 1.
7. 결과 화면. 민지·서아 공동 1등 "오늘의 분위기 메이커", 도윤이 최저점이라 벌칙 카드(가벼움)를 한 장 뽑아요. 카드: "지금 기분을 가장 어이없는 목소리로 외치고 박수 한 번". 도윤이 하고 다 같이 웃어요.
8. 도윤이 "패스"를 눌렀어도 아무 일도 안 생겨요. 끝나면 "한 판 더 / 다른 게임" 선택.
