# 술게임 — 카드 콘텐츠 (초안 v0.1)

작성: game-designer / 2026-11-12
용도: 개발자가 JSON으로 옮길 원본 표. 규칙은 `rules.md` 참고.
카드 문구는 전부 자체 창작이다. 기존 상용 술게임·방송의 고유 규칙명·문구는 쓰지 않았다.

## 1. 콘텐츠 작성 기준

### 1-1. 열 정의 (JSON 옮길 때 그대로 키로 쓰기)

| 열 | 뜻 |
|---|---|
| id | 카드 고유 번호. M(미션), P(벌칙), TQ(진실 질문), TD(도전), W(주제어), C(초성), B(폭탄 주제, 현재 미사용: 폭탄 판은 W 카드를 같이 씀) 뒤에 하이픈과 3자리 숫자를 붙임 (예: M-001) |
| 게임 | roulette(벌칙 룰렛), mission(미션 카드), truthdare(진실 혹은 도전), bomb(폭탄 돌리기), theme(초성/주제). 여러 게임에서 쓰면 쉼표로 구분 |
| 종류 | 미션 / 벌칙 / 진실 / 도전 / 주제 / 초성 / 폭탄주제 |
| 강도 | 1 가벼움 / 2 중간 / 3 센 편 (1-3 참조) |
| 음주 문구 | 음주 모드에서 보이는 문구 |
| 비음주 문구 | 비음주 모드에서 보이는 문구 |
| 비고 | 분류 태그(분위기, 말하기, 행동, 관찰, 칭찬 등), 쓰는 법 메모 |

- 미션·진실·도전·주제·초성은 마시는 내용이 없으니 두 문구가 같다. 그래도 빈칸 없이 양쪽 다 채워서 개발자가 모드 분기 없이 읽을 수 있게 했다.
- 벌칙 카드는 반드시 음주/비음주가 쌍이고, 비음주 쪽도 같은 수준으로 재밌게 썼다.
- 모든 카드는 "패스" 가능을 전제로 한다. 카드 문구에 패스 안내를 반복해서 쓰지 않아도 되고, 화면 하단 고정 버튼으로 처리한다.
- 팩 이름 필드(spec 6절)는 나중에 붙인다. 지금 카드는 전부 "기본팩" 가정.

### 1-2. 강도 기준

| 강도 | 이름 | 음주 모드 상한 | 비음주 쪽 기준 | 예 |
|---|---|---|---|---|
| 1 | 가벼움 | 한 모금(입만 대도 OK) | 말 한마디, 박수, 물 한 모금 정도 | 건배 외치기, 칭찬 한마디 |
| 2 | 중간 | 한 모금(1회). 행동 쪽이 살짝 민망한 정도 | 몸짓, 짧은 노래, 에피소드 말하기 | 성대모사, 에피소드 털어놓기 |
| 3 | 센 편 | 한 모금(1회, 강도 3이어도 마시는 양은 늘지 않음). 대신 행동 부담이 더 큼 | 조금 더 민망하지만 웃고 끝나는 수준 | 즉석 애교, 모임 규칙 만들기 |

- "센 편"도 몸이 위험한 것, 모욕, 성적 내용은 아니다. 민망함의 정도만 다르다.
- 기본 노출은 강도 1~2. 강도 3은 설정에서 켜야 나온다.
- 모임 분위기용 카드는 비고에 "분위기" 태그를 단다. 처음 만난 사람들, 어색한 자리에서 우선 노출하면 좋은 카드다.

### 1-4. 문체 기준
- 한 카드는 두 줄 이내(spec 8절). 음슴체나 명령형 호통 대신 "~해요/~하기" 정도의 말랑한 말투.
- 일상 상황(퇴근길, 치킨, 단톡방)에 엮어 풀어서 쓰기(스타일 가이드).
- 음주 문구에서 마시는 부분은 항상 맨 끝에 "(마실 사람만 한 모금)" 식으로 선택임을 드러낸다.
