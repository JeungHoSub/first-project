## 1. 채널 컨셉

"책 읽어주는 채널이 아니라, **책을 읽은 친구가 출근길에 들려주는 이야기**. 고전이든 신간이든 오늘 내 일상으로 풀어서."

### 1-2. 이름 후보 (3개)
| # | 이름 | 느낌 | 비고 |
|---|---|---|---|
| 1 | **책 읽은 친구** (추천) | "책을 읽은 친구가 얘기해 주는" 컨셉이 이름에 그대로 들어감. 고전·최신 모두 어울림 | 동일 이름 채널 중복 여부 미확인 |

### 1-3. 타깃 청취자 [가정]
- 20~40대 직장인·사회초년생. 책은 읽고 싶지만 시간·집중력이 없는 사람
- 청취 상황: 출퇴근길(화면 없이 이어폰), 집안일·산책
- 그래서 "화면 없이 이해되는 대본"이 최우선 (audio-lecture-script 기준)

## 2. 두 라인 운영 방식

| | 고전 라인 | 최신 책 라인 |
|---|---|---|
| 대상 | 저작권 만료 작품 | 최근 1~3년 출간 도서 |
| 원문 사용 | 해설 사이사이에 **직접 번역한 원문** 낭독 가능. **제안값: 전체 분량의 25~30% 이내**(17분 기준 약 1,300~1,500자). 나머지 70% 이상은 해설 | **짧은 인용만**. **제안값: 회당 최대 3문장, 문장당 짧게, 합계 전체 글자수의 3% 이내(약 150자)**. 인용은 말로 구분("저자는 이렇게 썼어요") |
| 번역 | **기존 국내 번역본 낭독 금지**(번역자 권리). 한국어 원작 또는 PD 원문을 직접 번역. 번역은 사람 검수 필수 | 번역서는 번역문 인용도 번역자 권리가 있으므로 인용 최소화 |
| 중심 | 옛날 이야기를 오늘 일상으로 옮기기 | 내 해석·적용·감상. 책 구매를 대체하지 않고 궁금하게 만들기 |
| 금지 | 번역자·판본 불명 텍스트 사용 | 장별 요약 이어붙이기, 핵심 결론·반전 전부 공개, 소설 줄거리·결말, 구절 모음집 다량 낭독, 표지·삽화 무단 사용 |
| 기록 | rights.md: 저자 사망 연도·판본·번역 출처 | rights.md: 인용 문장 수·위치(분:초)·출처 |

수치(25~30%, 3문장, 3%)는 **운영 기준 제안값**이며 법적 안전선이 아니다. reviewer가 매회 점검하고, 사용자 승인 전 저작권위원회 상담 등 전문가 확인을 권장한다.

### 회차 비율 [가정]
- **고전 2 : 최신 1** (3회 주기: 고전, 고전, 최신)
- 이유: 고전은 저작권 리스크가 낮고 원문 활용 폭이 넓어 안정적. 최신은 화제성·검색 유입용이라 비중을 낮게.
- 단, **첫 5편은 두 라인을 모두 시험하기 위해 고전 3 + 최신 2**로 운영(roadmap 2단계). 이후 2:1로 수렴.
- 고전 라인은 시리즈화 가능한 책(『명상록』 등)을 우선: 같은 책에서 여러 회 → 제작 부담 감소(재활용 원칙).
- 최신 라인 연계: 고전 소개서(예: 『청춘의 독서』)를 활용한 "고전 ↔ 최신" 연결 기획 가능(후순위).

## 3. 회차 형식

### 3-1. 분량 [가정: 15~20분]
- 1분 ≈ 300자(audio-lecture-script). 기본 **약 17분 ≈ 5,100자** (허용 범위 4,500~6,000자)
- 꼭지 3~5개 (기본 4개). 개념 과다 방지: 한 회 핵심 메시지 4개 이하 권장

### 3-2. 타임라인 (book-explainer 구조 기반, 17분 기준)
| 시간 | 구간 | 내용 | 글자수 |
|---|---|---|---|
| 0:00~0:30 | 훅 | 오늘의 일상 장면 한 컷 (회차마다 다른 방식) | 150 |
| 0:30~1:30 | 오프닝 | 이 책을 왜 골랐나, 오늘 들을 것 한 줄 | 300 |
| 1:30~5:00 | 꼭지 1 | ①장면 30초 ②책은 이렇게 말한다 1분 ③무슨 뜻이냐면(비유) 1분 ④내 삶에 적용(행동 1개) 45초 ⑤한 줄 정리 15초 | 1,050 |
| 5:00~8:30 | 꼭지 2 | 위와 동일 구조 | 1,050 |
| 8:30~12:00 | 꼭지 3 | 위와 동일 구조 | 1,050 |
| 12:00~15:30 | 꼭지 4 | 위와 동일 구조 | 1,050 |
| 15:30~17:00 | 클로징 | 전체 3줄 복습, 이 책이 맞는 사람, 실천 과제 1개, 다음 회 예고 | 450 |
| 합계 | | | 약 5,100 |

- 고전 회차: 꼭지의 "책은 이렇게 말한다"에서 원문 낭독 포함 (2장 비율 준수)
- 최신 회차: 같은 구조이되 인용은 꼭지당 1문장 이하
- 듣기 규칙: 짧은 문장, 표·URL·기호 금지, 영어 용어는 한국어 설명, "첫째·둘째" 위치어, 중요한 문장 반복

### 3-3. 변주 규칙 (비진정성 콘텐츠 회피 — 5장과 연결)
고정 구조는 유지하되, 회차마다 아래를 **의도적으로 바꾼다**.
- 훅 방식 순환 (장면 / 질문 / 짧은 사연 / 반전 문장)
- 꼭지 수(3~5)와 순서, 비유 소재, 일상 장면 (직장·가족·돈·인간관계 돌려쓰기)
- 제목 패턴, 썸네일 배경 구도
- 회당 최소 1개의 **사람의 판단이 들어간 요소**(운영자 사례·의견, 또는 사람이 고른 책·꼭지 선택 이유)를 대본에 넣고 검수 기록에 남긴다

## 6. 재활용 구조 (하나 만들어 여러 곳에)

```
본편 대본(script.md) ─┬→ TTS 오디오 → 본편 영상 (16:9)
                      ├→ 쇼츠 후보 추출 → shorts-auto 프로젝트 (세로 9:16)
                      ├→ 오디오 단독 (팟캐스트 RSS 등, 후순위)
                      └→ 블로그·뉴스레터 글 (후순위)
고전 시리즈: 같은 책 여러 회 → 원문·번역·rights.md 재사용
```

1. **쇼츠 추출** (shorts-auto와 공유): 꼭지 구조 덕분에 "장면 + 한 줄 정리"가 30~60초 단위로 이미 나뉘어 있다.
   - 대본 작성 시 content-writer가 `epNNN/shorts-candidates.md`에 후보 2~3개를 표시(꼭지 번호, 시작·끝 시간, 훅 문장, 쇼츠용 제목).
   - media-producer가 본편 오디오·타이밍에서 해당 구간을 잘라 세로 영상으로 변환하거나, shorts-auto가 이 파일을 입력으로 사용.
   - 쇼츠에도 인용 상한·rights.md 기준을 동일 적용. 쇼츠는 본편 유입 목적(설명란/고정 댓글에 본편 링크).
   - **shorts-auto 쪽 입력 형식은 아직 협의 전**: 총괄이 두 프로젝트 간 파일 형식을 맞춘다.
2. **업로드 모듈**: 쇼츠·음악·책 채널 공통이므로 `projects/shared/`(예: `projects/shared/youtube_upload/`)에 한 번만 만든다. book-podcast는 `metadata.json` 규격만 정하고 코드는 shared 것을 호출. 채널별 OAuth 토큰·`client_secret.json`은 git 제외.
3. **TTS·영상 템플릿**(배경·자막 스타일, ffmpeg 스크립트)도 shared 후보. 음악 프로젝트와 겹치면 승격.
4. 대본 템플릿·검수 체크리스트는 매회 동일하게 재사용하되, 3-3 변주 규칙으로 반복감은 줄인다.

- [ ] 제목·썸네일 과장·낚시 금지, 설명에 출처·판본 기재
