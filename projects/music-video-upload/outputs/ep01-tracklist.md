# EP01 — 늦가을 밤, 편하게 듣는 노래 (곡 설계서)

> 사용자 취향(2026-11-13): 2000년대 감성 발라드(이수영 같은 맑고 애절한 여성 보컬), 대중가요, 감미로운 힙합.
> 목표: 12곡 × 약 2분 40초 ≈ 30분 → 같은 30분을 2번 이어 1시간 영상.

## 먼저 알아둘 것
- **가수 이름은 프롬프트에 넣지 않는다.** Suno는 실존 가수 이름을 넣으면 막고, 특정 가수 목소리를 흉내 내는 건 퍼블리시티권·저작권 분쟁 위험이 있다. 대신 "2000년대 K-발라드, 맑고 높은 여성 보컬"처럼 **분위기를 말로 풀어서** 적었다.
- 가사는 전부 이 문서에서 새로 쓴 창작 가사다. 직접 쓴 가사를 넣으면 "사람이 만든 부분"이 생겨서 YouTube의 대량생산 콘텐츠 정책과 저작권 면에서도 유리하다.
- 흐름: 발라드와 힙합/R&B를 번갈아 배치해서 30분 내내 같은 느낌이 이어지지 않게 했다. 앞부분은 잔잔하게, 중간은 조금 밝게, 끝은 잠들기 좋게 내려간다.

## Suno에서 만드는 법 (곡마다 반복)
1. **유료 플랜(Pro 이상)에 가입한 뒤** 만든다. 무료로 만든 곡은 나중에 유료로 바꿔도 수익화 권리가 생기지 않는다(2차 자료 기준).
2. Create → **Custom** 모드
3. **Lyrics** 칸에 아래 가사를 `[Verse]` 같은 태그까지 통째로 붙여넣기
4. **Style** 칸에 아래 영어 스타일 문구 붙여넣기
5. **Title**에 곡 제목
6. 한 번 생성하면 2곡이 나온다 → 둘 다 들어보고 좋은 것 1곡만 **다운로드(MP3)**. 마음에 안 들면 다시 생성해도 된다(생성은 넉넉하고, 상한은 *다운로드* 수에 걸려 있다).
7. 파일 이름을 `01 첫눈이 오기 전에.mp3` 처럼 **번호 + 공백 + 제목**으로 바꿔 한 폴더(`songs/`)에 모은다.
8. 곡마다 생성일, 플랜, 화면 캡처를 `rights.md`에 기록한다.

> 길이: 곡이 3분을 많이 넘으면 30분을 넘긴다. 12곡 합이 28~34분이면 괜찮다. 너무 길면 한두 곡을 빼면 된다(10~11곡도 OK).

## 곡을 다 모은 다음 (영상 만들기)
PC에 Python과 ffmpeg가 있으면 아래 한 줄로 1시간 영상, 썸네일, 타임스탬프가 한 번에 나온다. 사용법은 `tools/README.md`를 참고한다.

```
python tools/make_playlist_video.py --songs ./songs --out ./ep01 \
  --title "늦가을 밤, 편하게 듣는 노래" --subtitle "감성 발라드 & 멜로우 힙합 플레이리스트" \
  --bg ./bg.jpg
```

- 배경 이미지(`--bg`)가 없으면 늦은 밤 느낌의 그라데이션 배경으로 만든다.
- 배경 이미지도 저작권 확인이 필요하다. 직접 찍은 사진이나 AI 이미지(상업 이용 가능 플랜)를 쓰고 `rights.md`에 기록한다.
