## 1. 실무에서 꼭 알아야 하는 것

한 줄로 말하면, 포렌식은 **"컴퓨터에 남은 흔적으로 '누가, 언제, 무엇을 했는지'를 법정에서 통하는 방식으로 증명하는 일"**이다.
핵심은 "찾는 기술"보다 **"찾은 것이 증거로 인정되게 다루는 방법"**이다. 범죄 현장 감식반이 지문을 찾는 것보다 지문을 오염 없이 채취·보관하는 데 더 신경 쓰는 것과 같다.

### 1-1. 포렌식 분야 지도

| 분야 | 무엇을 보나 | 대표 상황 |
|---|---|---|
| 컴퓨터(디스크) 포렌식 | 하드디스크·SSD의 파일시스템, 삭제 파일, OS 흔적 | 횡령·기술유출 PC 조사 |
| 모바일 포렌식 | 스마트폰 앱 DB, 메신저, 위치, 사진 메타데이터 | 형사사건, 이혼·민사 |
| 메모리 포렌식 | 실행 중인 RAM: 프로세스, 네트워크 연결, 암호 키 | 해킹·악성코드 사고 |
| 네트워크 포렌식 | 패킷(pcap), 방화벽·프록시 로그, NetFlow | 유출 경로 추적 |
| 침해사고 대응(DFIR) | 위 모든 것 + 악성코드 분석 + 복구 | 랜섬웨어, APT |
| 클라우드/SaaS 포렌식 | M365·Google Workspace·AWS 감사로그 | 계정 탈취, 메일 유출 |
| 악성코드 분석 | 리버스 엔지니어링으로 악성코드 동작 해석 | 사고 원인 규명 |
| 멀티미디어 포렌식 | 이미지·영상·음성 위변조, 딥페이크 | 조작 영상, 보이스피싱 |
| 암호화폐 포렌식 | 블록체인 거래 추적 | 자금세탁, 사기 |
| eDiscovery | 소송용 대량 문서·이메일 검색·검토 | 기업 소송(주로 미국) |

### 1-2. 표준 절차 (이 순서가 몸에 배야 함)

1. **준비** — 장비, 쓰기방지장치, 저장매체, 서류(동의서·압수목록)
2. **식별** — 어떤 기기·계정·로그에 증거가 있을지 범위 확정
3. **수집(획득)** — 원본은 건드리지 않고 **비트 단위 복제(이미징)**. 휘발성 높은 것부터(RFC 3227: 레지스터·캐시 → RAM → 네트워크 상태 → 디스크 → 백업)
4. **보존** — 해시값(SHA-256 등) 계산·기록, 봉인, **연계보관(Chain of Custody)** 기록
5. **분석** — 사본으로만 작업. 타임라인 만들고 가설 세우고 검증
6. **보고** — 비전문가(판사·임원)가 읽을 수 있게. 재현 가능한 근거 첨부
7. **증언** — 필요 시 법정에서 방법론 설명

참고 표준: NIST SP 800-86, ISO/IEC 27037(수집·보존)·27041·27042(분석)·27043(조사 절차), 실험실 인증은 ISO/IEC 17025.

### 1-3. 증거능력 5원칙 (시험에도, 실무에도 나옴)

| 원칙 | 뜻 | 일상 비유 |
|---|---|---|
| 정당성 | 적법한 절차(영장·동의·계약)로 얻었나 | 남의 집 몰래 들어가 찾은 건 무효 |
| 무결성 | 수집 후 바뀌지 않았나 (해시로 증명) | 봉인 테이프가 안 뜯겼나 |
| 재현성 | 같은 방법이면 같은 결과가 나오나 | 레시피대로 하면 같은 맛 |
| 신속성 | 사라지기 전에 빨리 확보했나 | 휘발성 데이터 |
| 연계보관성 | 누가 언제 증거를 만졌는지 끊김 없는 기록 | 택배 배송 추적 |

### 1-4. 한국 법·판례 기본 (실무자가 자주 부딪히는 것)

- **형사소송법 제106조 제3항** — 저장매체는 원칙적으로 **필요한 범위만 출력·복제**해서 압수. 통째 압수(이미징 반출)는 예외.
- **피압수자 참여권** — 선별·복제 과정에 당사자 참여 기회를 줘야 함 (대법원 2015. 7. 16. 2011모1839 전원합의체, 일명 '종근당 사건'). 무관 정보를 함께 가져가면 위법 소지.
- **형사소송법 제313조(2016 개정)** — 디지털 문서도 작성자가 부인할 때 **포렌식 등 객관적 방법**으로 성립의 진정을 증명할 수 있게 됨.
- 수사기관 내부 규정: 대검찰청 「디지털 증거의 수집·분석 및 관리 규정」, 경찰청 「디지털 증거의 처리 등에 관한 규칙」.
- 민간에서 특히 조심: **개인정보보호법, 통신비밀보호법, 정보통신망법**(권한 없는 계정 접속), **변호사법**(법률 판단을 대신 해주면 비변호사 법률사무 문제). 의뢰인이 "배우자 폰 몰래 봐 달라"는 건 받으면 안 되는 일.

### 1-5. 꼭 아는 아티팩트(흔적) — Windows 중심

"아티팩트"는 OS와 앱이 **사용자가 의도하지 않아도 남기는 기록**이다. 포렌식 실력의 상당 부분이 "어디에 무엇이 남는지 아는 것"이다.

| 알고 싶은 것 | 보는 곳 |
|---|---|
| 파일이 언제 생기고 바뀌었나 | NTFS `$MFT`(타임스탬프 MACB), `$UsnJrnl`(변경 일지), `$LogFile` |
| 이 프로그램 실행했나 | Prefetch, Amcache, Shimcache, UserAssist, SRUM, 이벤트 4688 |
| 이 파일·폴더 열어봤나 | LNK 파일, Jump Lists, ShellBags, RecentDocs |
| USB 꽂았나 | 레지스트리 `SYSTEM\...\USBSTOR`, `setupapi.dev.log`, 이벤트 로그 |
| 누가 로그인했나 | 보안 이벤트 4624(성공)/4625(실패), RDP 관련 로그 |
| 흔적 지우려 했나 | 이벤트 1102(로그 삭제), 안티포렌식 도구 실행 흔적, 타임스탬프 조작 |
| 지운 파일 | 휴지통 `$I/$R`, 볼륨 섀도 복사본(VSS), 비할당 영역 카빙 |
| 웹 활동 | 브라우저 History/Cookies SQLite DB |

- **Mac**: Unified Logs, FSEvents, KnowledgeC, Spotlight
- **Linux**: `/var/log`, journald, `.bash_history`, cron, `auth.log`
- **모바일**: 대부분의 앱 데이터는 **SQLite DB**(+WAL 파일에 최근 삭제 흔적). 추출 방식은 논리 → 파일시스템 → 물리(전체) → 칩오프 순으로 깊어진다. 최신 폰은 암호화 때문에 잠금해제가 핵심 병목.

### 1-6. 도구

| 구분 | 도구 | 비고 |
|---|---|---|

### 1-8. 실무 직업군 (어디서 돈을 받나)

- **수사기관**: 대검 국가디지털포렌식센터, 경찰청·지방청 디지털포렌식센터, 국과수, 군·관세청·공정위·금감원 등

- **도구 개발사**: 파서·분석 엔진 개발 (여기서 프로그래밍이 핵심)

## 2. 포렌식 × AI 결합 사업

포렌식의 가장 큰 고통은 **"데이터가 너무 많다"**이다. 휴대폰 한 대에 사진 수만 장, 메시지 수십만 건. 그래서 AI는 크게 세 방향으로 들어온다.

### 2-1. AI가 포렌식을 돕는 쪽 (도구·효율)

| 사업 | 내용 | 실제 예 |
|---|---|---|
| 증거 검토 자동화 | 사진·영상 분류(무기·마약·아동착취물), 얼굴·객체 인식, OCR, 음성 STT | Griffeye, Magnet AXIOM, Cellebrite |
| LLM 대화·문서 분석 | 메신저 수십만 건 요약, 인물·관계·사건 추출, 자연어 질의("3월에 돈 얘기한 대화 찾아줘") | Cellebrite·Magnet의 AI 어시스턴트 기능, Relativity aiR·Everlaw(eDiscovery) |
| 침해사고 자동 트리아지 | 로그·EDR 경보를 AI가 묶고 설명, 대응 절차 제안 | Microsoft Security Copilot, 각종 SOC AI |
| 악성코드 분석 보조 | 디컴파일 코드 설명, 행위 요약, 탐지 룰(YARA·Sigma) 초안 | 리버싱 도구용 AI 플러그인 |
| 보고서 자동 작성 | 분석 결과를 사람이 읽는 보고서 초안으로 | 많은 툴이 추가 중 |

### 2-2. AI가 만든 문제를 포렌식이 푸는 쪽 (신규 수요)

| 사업 | 내용 | 실제 예 |
|---|---|---|
| 딥페이크·합성미디어 탐지 | 영상·이미지·음성 조작 여부 판별, 법정 감정 | Reality Defender, Sensity, Intel FakeCatcher, 국내 AI 기업·국과수 |
| 음성 위조(보이스피싱) 탐지 | 합성 음성 판별 | 금융권·통신사 연계 |
| 문서·신분증 위변조 탐지 | 보험 청구, KYC 사진 조작 | 보험·핀테크 |
| 콘텐츠 출처 증명 | C2PA 콘텐츠 자격증명, 워터마크 검증 | Adobe 주도 C2PA 생태계 |
| AI 시스템 사고 조사 | AI 에이전트·LLM 오남용 흔적, 프롬프트 인젝션 사고 조사 | 초기 시장 |

### 2-3. 데이터 연결·추적 쪽

- **암호화폐 추적**: 지갑 군집화, 자금 흐름 그래프 (Chainalysis, Elliptic, TRM Labs)
- **OSINT(공개정보) 분석**: SNS·웹 흔적 연결, 사기 조직 추적

### 2-4. 사용자(나)에게 현실적인 진입 아이템

규칙: **하나 만들어 여러 곳에 재활용**하는 구조(스타일 가이드) 기준으로 골랐다.

| 아이템 | 설명 | 장점 | 주의 |
|---|---|---|---|
| A. 대화 증거 정리 리포트 | 의뢰인이 **본인 휴대폰**에서 정상 추출한 카톡·문자 백업을 AI로 타임라인·요약 보고서화 → 변호사·노무사에게 납품 | 작게 시작 가능, LLM과 궁합 최고 | 본인 데이터만, 법률 판단 금지, 개인정보 처리 동의 |
| B. 중소기업 퇴사자 유출 점검 패키지 | 회사 소유 PC를 표준 절차로 이미징 → 자동 아티팩트 파싱(USB·클라우드 업로드·대량 복사) → AI 요약 | 반복 가능한 상품, 정기 계약 가능 | 회사 동의·사내 규정 근거 필요 |
| C. 딥페이크 판별 1차 스크리닝 | 공개 탐지 모델 여러 개를 묶어 1차 판정 + 전문가 감정 연결 | 수요 급증 | 오판 책임, 법정 감정은 전문기관 영역 |
| D. 포렌식 교육 콘텐츠 | 공부한 것을 오디오 강의·유튜브로 | 공부 = 콘텐츠, 기존 강의 프로젝트와 재활용 | 실제 사건 정보 노출 금지 |
| E. 오픈소스 파서 + AI 보고서 도구 | 국내 앱(카카오톡·네이버 등) 아티팩트 파서 | 기술력 증명 포트폴리오, 취업·외주로 연결 | 앱 암호화 분석은 법적 검토 |

추천 순서: **D(공부하며 바로) → E(포트폴리오) → A 또는 B(첫 매출)**. 기술력이 먼저라는 판단이 맞고, D와 E가 그 기술력을 쌓는 과정 자체다.

## 3. 한국과 세계의 포렌식 수준, 그리고 "포렌식 잘함"의 정체

### 3-1. 수준 비교

| 항목 | 한국 | 세계(미국·유럽·이스라엘) |
|---|---|---|
| 수사기관 역량 | 높음. 대검 NDFC, 경찰, 국과수가 체계적. 압수 휴대폰 분석 물량이 매우 많아 실전 경험 풍부 | 미국 FBI·NIST가 표준과 연구를 주도 |
| 모바일 | **강점**. 삼성 폰·카카오톡 환경에 특화, GMDSOFT 등 국산 도구가 해외 수출 | Cellebrite(이스라엘)가 시장 지배, 잠금해제 기술 선도 |
| 컴퓨터·DFIR 도구 | 상용 툴 대부분 수입 의존 | EnCase·FTK·AXIOM·X-Ways 모두 북미·유럽 |
| 민간 시장 | 작고 수사 지원·형사사건 중심 | eDiscovery·사이버보험·DFIR 리테이너로 큼 |
| 교육·자격 | 학회 자격, 대학원(고려대 등) 중심 | SANS·GIAC 생태계, 커리어 경로 명확 |
| 연구 | 학회·대학 연구 활발 | DFRWS 등 국제 학회, 오픈소스 커뮤니티 두꺼움 |

요약: 한국은 **"수사기관 실전 + 모바일"**은 세계권, **"민간 산업·상용 도구·표준"**은 추격자.

### 3-2. 포렌식을 잘한다 = 프로그래밍을 잘한다?

**아니다. 정확히는 "필요조건은 아니지만 강력한 배율기"다.**

포렌식 실력을 비율로 그려 보면 대략:

- **시스템 내부 구조 이해** (파일시스템·OS·앱이 데이터를 어떻게 저장하나) — 가장 큰 비중
- **조사 사고력** (가설 → 검증 → 반증 찾기, 타임라인 맞추기) — 탐정 능력
- **절차·법 감각** (증거능력 지키기) — 이게 없으면 실력이 있어도 증거가 무효
- **보고·설명 능력** (판사·임원이 이해하게) — 의외로 연봉을 가르는 능력
- **프로그래밍** (Python·SQL·정규식) — 도구에 없는 아티팩트를 직접 파싱, 대량 자동화. **상위권과 중위권을 가르는 지점**
- **리버스 엔지니어링** — 악성코드 분석, 앱 DB 암호화 해제 연구. 특정 직무(악성코드 분석가·도구 개발자)에선 핵심, 일반 조사관에겐 선택

### 3-3. 해킹·리버싱·포렌식은 어디에 속하나

디지털 포렌식은 **부모가 둘**이다.

- **법과학(Forensic Science)** 의 한 분과 — 지문·DNA·필적 감정과 형제. "증거를 다루는 학문"
- **정보보안(사이버보안)** 의 방어(블루팀) 쪽 — 특히 침해사고 대응(DFIR)

관계:

- **해킹(공격·레드팀)**: 시스템에 흔적을 **남기는** 쪽. 포렌식은 그 흔적을 **읽는** 쪽. 같은 지식(OS 내부, 권한, 로그)을 반대 방향에서 씀. 공격 기법을 알아야 흔적을 찾을 수 있어서 많이 겹친다.
- **리버스 엔지니어링**: 독립된 "기술"이다. 해킹(취약점 찾기)과 포렌식(악성코드·앱 구조 분석) **둘 다에 쓰이는 공용 도구**에 가깝다.
- **프로그래밍**: 세 분야 모두의 바닥에 깔린 공통 기반.

시각화(벤다이어그램·계보도·직무별 기술 비중)는 HTML 아티팩트에 있다: `outputs/02-forensics-skill-map.html`

## 4. 한국 vs 세계 포렌식 사업모델

### 4-1. 한국에서 흔한 사업모델

| 모델 | 고객 | 수익 구조 | 특징 |
|---|---|---|---|
| 수사기관 도구·장비 납품 | 검찰·경찰·군·공공 | 조달 입찰, 라이선스+유지보수 | B2G 중심. 모바일 도구 업체가 대표 |
| 포렌식 교육·자격 | 수사관, 취준생 | 교육비 | 학회·업체 교육과정 |
| 민간 "휴대폰 포렌식" 업체 | 개인(형사 피의자·피해자, 이혼·민사) | 건당 수십만~수백만 원 | B2C, 광고 경쟁 치열, 품질 편차 큼 |
| 회계법인·법무법인 포렌식팀 | 대기업, 로펌 | 투입 인력 × 시간(타임차지) | 횡령·부정·기술유출 조사 |
| 보안업체 침해사고 대응 | 기업·기관 | 사고 건별, 관제 계약 부가 | 랜섬웨어 대응 |
| 디지털 장의·평판 관리 | 개인 | 건당·월정액 | 포렌식 주변 산업 |

### 4-2. 세계적으로 커지는 사업모델

| 모델 | 고객 | 수익 구조 | 왜 큰가 |
|---|---|---|---|
| **eDiscovery 플랫폼** | 로펌, 기업 법무 | SaaS, 데이터 용량(GB)당 과금 | 미국 소송의 **증거개시(Discovery) 제도** → 상대방에게 자료를 대량 제출·검토해야 함. 최대 시장 |
| **DFIR 리테이너 + 사이버보험** | 기업 | 연간 선계약(사고 시 즉시 출동), 보험사 패널 벤더 | 랜섬웨어 → 보험사가 지정 업체 비용을 지급 |
| **수사 플랫폼 SaaS 전환** | 수사기관 | 도구 판매 → 구독형 클라우드 플랫폼(증거 관리·협업·AI 검토 통합) | 장비 판매보다 반복 매출 |
| **MDR + 포렌식 결합** | 기업 | 월 구독 관제 + 사고 시 포렌식 | 탐지와 조사를 한 업체가 |
| **블록체인 포렌식** | 수사기관, 거래소, 금융 | 데이터 구독 라이선스 | 가상자산 범죄·규제 |
| **딥페이크·위변조 탐지 API** | 금융, 플랫폼, 언론 | API 호출당 과금 | 생성형 AI 확산 |
| **Forensics-as-a-Service** | 중소기업, 소규모 기관 | 원격 수집 에이전트 + 구독 | 자체 인력 없는 조직 |

### 4-3. 결정적 차이 3가지

1. **제도가 시장을 만든다.** 미국은 디스커버리 제도와 사이버보험이 "의무적으로 써야 하는 돈"을 만든다. 한국은 디스커버리 제도가 없고(특허 소송 중심으로 도입 논의만 있는 상태), 그래서 민간 수요가 형사사건·내부조사에 머문다.
2. **팔아치우기 vs 구독.** 한국은 라이선스·건당·인력투입 위주. 세계는 SaaS·리테이너·데이터 구독 같은 **반복 매출**로 이동했다.
3. **고객이 다르다.** 한국은 정부(B2G)와 개인(B2C)이 양 끝. 세계는 중간의 **기업·로펌·보험사(B2B)**가 가장 두껍다.

### 4-4. 시사점 (내 기회)

- 한국 B2C 휴대폰 포렌식은 이미 레드오션. 차별점은 **"AI로 정리된, 변호사가 바로 쓰는 보고서"** 품질.
- 한국 중소기업은 기술유출·퇴사자 문제가 크지만 대기업처럼 Big4를 쓸 돈이 없다 → **표준화된 저가 패키지 + 구독**(세계형 모델의 축소판)이 빈 자리.
- 디스커버리 제도가 도입되면 eDiscovery 시장이 열린다. 지금은 관심 목록에 두고 추적.
