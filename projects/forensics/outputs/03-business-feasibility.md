# 포렌식 사업 수익구조 실현가능성 검토 (1차)

작성: 2026-11-19 · 메인 세션 직접 작성
전제: "바로 사업을 열어 돈을 버는 구조"가 목표. 현재 실무 기술은 학습 시작 단계.
주의: 가격·매출 숫자는 **업계 통상 수준을 바탕으로 한 추정**이다. 실제 개업 전 researcher로 경쟁업체 가격표·견적을 조사해 확정한다.

---

## 결론 먼저

| 수익구조 | 바로 돈 되나 | 1인 실현가능성 | 한 줄 평가 |
|---|---|---|---|
| ① 개인 데이터 복구·포렌식 | 가능 (3개월 내 첫 매출) | 높음 | 시작은 쉽지만 광고 경쟁과 **기술적 복구 한계**가 벽. "복구"보다 **"증거용 분석"**으로 가야 단가가 나온다 |
| ② 포렌식 도구 판매 (수사기관·업체) | 어렵다 (2~3년) | 낮음 | 정면 승부는 대기업·글로벌 업체 영역. **민간 업체·로펌용 틈새 도구**로 바꾸면 가능 |
| 추천 구조 | ①로 현금흐름 → ①에서 쓰던 내부 도구를 ②로 판매 | | 하나 만들어 재활용하는 구조 |

## ① 개인 대상 데이터 복구·포렌식

### 현실 1. 시장은 있다
- 수요층: 실수로 지운 사진·카톡, 고장 난 폰·하드, **형사사건(피의자·피해자), 이혼·양육권 소송, 직장 내 괴롭힘·임금 분쟁, 사기 피해** 증거 확보
- 네이버에 "휴대폰 포렌식", "카톡 복구"를 검색하면 업체가 많다 = 수요가 검증된 시장이면서 경쟁이 치열한 시장

### 현실 2. "잃어버린 데이터 찾기"는 기술적으로 점점 어려워진다 (가장 중요한 현실)
| 상황 | 복구 가능성 | 이유 |
|---|---|---|
| 고장 난 HDD(물리 손상) | 중~높음 | 장비·부품·클린룸 필요, 기술자 숙련도에 좌우 |
| SSD에서 지운 파일 | **낮음** | TRIM 기능이 삭제 즉시 실제 데이터를 지움 |
| 최신 아이폰·안드로이드에서 지운 사진·파일 | **낮음** | 파일 단위 암호화로, 지우면 키가 사라짐 |
| 카톡 삭제 메시지 | 경우에 따라 | DB 잔여 영역·백업·상대방 기기 등에 남아 있을 때만 |
| 잠금 걸린 폰(비번 모름) | 매우 낮음~불가 | 수사기관용 고가 장비 영역, 그래도 안 되는 기종 많음 |
| 클라우드 백업이 있는 경우 | 높음 | 사실상 "찾아서 정리"하는 작업 |

그래서 업계는 대부분 **"진단비 + 성공 시 복구비"** 구조다. 실패 건이 많으면 시간만 쓰고 돈을 못 받는다.

### 현실 3. 돈은 "복구"보다 "증거 분석 보고서"에서 나온다
| 서비스 | 단가(추정) | 특징 |
|---|---|---|
| 단순 논리 복구(실수 삭제, 포맷) | 수만~30만 원 | 무료 도구로도 되는 건이 많아 가격 경쟁 |
| 물리 손상 복구(HDD 헤드 등) | 50만~수백만 원 | 장비·부품 투자 필요, 전문 기술 |
| 휴대폰 데이터 추출 + 분석 보고서 | 수십만~100만 원대 | 형사·민사 사건용. 변호사가 고객을 데려옴 |
| 법정 제출용 감정 보고서 + 증언 | 건당 100만 원 이상 | 자격·경력·평판이 있어야 받음 |

### 현실 4. 1인 매출 시나리오 (추정)
| 구분 | 보수적 | 보통 | 잘 될 때 |
|---|---|---|---|
| 월 건수 | 10건 | 20건 | 40건 |
| 평균 단가 | 30만 원 | 45만 원 | 60만 원 |
| 월 매출 | 300만 원 | 900만 원 | 2,400만 원 |
| 광고·장비·임대 등 비용 | 매출의 30~50% | | |

- 초기 투자(추정): 노트북·쓰기방지장치·저장장치 수백만 원 / 모바일 상용 장비 라이선스 연 수천만 원대(견적 필요) / 물리 복구 장비·클린벤치 수백~수천만 원
- 광고: 네이버 키워드 단가가 높은 업종이라 광고비가 수익을 갉아먹는다. **변호사·노무사 제휴(소개 채널)**가 광고보다 효율적이다.

### 현실 5. 법·책임 체크리스트
| 상황 | 해야 할 것 |
|---|---|
| 본인 기기 | 소유·사용자 확인(신분증·구매 정보), 의뢰서·개인정보 수집이용 동의, 작업 후 사본 파기 확인서 |
| 타인 기기 | **소유자 동의가 없으면 거절**이 원칙. "배우자·연인 폰 봐 달라"는 통신비밀보호법·정보통신망법 위반 공범 위험 |
| 회사 소유 PC | 회사가 의뢰 가능하나 직원 사생활 정보 분리, 사내 규정·동의서 근거 확인 |
| 사망자 기기 | 유족 요청, 상속 관계 확인. 법적 회색지대가 있어 보수적으로 |
| 증거용 작업 | 해시 기록, 연계보관 기록, 작업 과정 재현 가능하게 문서화 |
| 결과 해석 | "이 증거로 이긴다" 같은 법률 판단은 하지 않는다(변호사법) |

- 데이터 복구·포렌식은 별도 인허가 없이 사업자등록으로 시작하는 것으로 알고 있으나, 개업 전 확인 필요
- **배상책임보험** 가입 권장: 작업 중 데이터 손상 분쟁 대비
- 기술이 부족한 상태에서 증거 작업을 받으면 증거 훼손 → 손해배상 위험. 지금 단계에서 가장 큰 리스크

### ①의 판정
- 실현가능성 **높음**, 다만 "복구 장인" 경쟁으로 가면 기술·장비에서 밀린다.
- 차별화 방향: **AI로 정리된, 변호사가 바로 쓰는 증거 보고서** + 빠른 처리 + 투명한 가격·개인정보 처리.

## ② 포렌식 도구 판매

### 현실 1. 수사기관 정면 판매는 1인이 단기간에 할 수 없다
| 벽 | 내용 |
|---|---|
| 기존 강자 | 모바일: Cellebrite, GMDSOFT 등 / 컴퓨터: EnCase, FTK, AXIOM 등이 이미 납품 중 |
| 기술 | 모바일 잠금해제·전체 추출은 취약점 연구 전담팀이 필요한 수준 |
| 조달 | 조달청 등록, 소프트웨어 품질인증(GS인증 등), 납품 실적 요구 |
| 영업 주기 | 예산 편성 → 입찰까지 1~2년 |
| 신뢰 | 법정에서 결과가 검증된 도구여야 함(도구 검증 이력) |

→ **단기 수익원으로는 비현실적.** 장기 목표로만.

### 현실 2. 틈새는 있다: 고객을 바꾸면 된다
| 틈새 도구 | 고객 | 수익 방식 | 실현가능성 |
|---|---|---|---|
| AI 증거 보고서 생성기 (기존 도구 결과를 읽어 타임라인·요약·보고서 초안) | 민간 포렌식 업체, 로펌 | 월 구독 | **높음** — 내가 ①에서 먼저 쓰면서 만들 수 있음 |
| 국내 앱 아티팩트 파서 (특정 메신저·쇼핑·금융 앱) | 민간 업체, 연구자 | 라이선스, 기존 툴 플러그인 | 중간 — 리버싱 실력 필요 |
| 사건·증거물 관리 SaaS (접수, 동의서, 연계보관 기록, 파기 증명) | 민간 포렌식·복구 업체 | 월 구독 | **높음** — 포렌식 기술보다 개발 실력 영역 |
| 기업용 퇴사자 점검 자동화 에이전트 | 중소기업, 보안업체 | 건당·구독 | 중간 |

### ②의 판정
- "수사기관에 파는 도구"는 **3년 이상 장기 목표**.
- 단기에는 **민간 업체·로펌용 업무 도구(SaaS)**로 방향을 바꾸면 1년 안에 매출 가능성 있음. 같은 업계 사람들이 고객이라 ①을 하면서 인맥이 곧 영업망이 된다.

## ③ 다른 수익화 방안

| 방안 | 고객 | 단가·구조(추정) | 법적 깔끔함 | 기술 난이도 | 메모 |
|---|---|---|---|---|---|
| **스파이앱·도청앱 점검** | 스토킹·이별 후 불안한 개인 | 건당 수만~20만 원 | 매우 깔끔(본인 폰) | 낮~중 | 수요 크고 복구보다 성공률 높음 |
| **데이터 완전삭제 + 삭제 확인서** | 기업(자산 폐기), 중고폰 판매자 | 대당 과금, 기업 정기계약 | 깔끔 | 낮음 | 복구의 반대. 안정적 B2B |
| **중소기업 퇴사자 유출 점검 패키지** | 중소기업 | 건당 수백만 원대 | 회사 동의 필요 | 중 | 고단가, 반복 가능 |
| 변호사·노무사 제휴 증거 정리 | 로펌, 노무법인 | 건당, 월 제휴 | 깔끔(의뢰인 동의) | 낮~중 | **본인이 직접 백업한 카톡·문자를 AI로 타임라인화** → 복구가 아니라 정리라 실패가 없음 |
| 디지털 유산 정리 | 유족 | 건당 | 회색지대 있음 | 중 | 고령화로 수요 증가 |
| 딥페이크·조작 이미지 1차 검토 | 개인 피해자, 기업 | 건당 | 깔끔 | 중 | 최종 감정은 전문기관 연계 |
| 보안업체·Big4 외주 인력 | 보안업체, 회계법인 | 일당·월 단위 | 깔끔 | 중~높 | 자격증·경력 쌓으면서 수익 |
| 교육·콘텐츠 | 일반인, 취준생, 기업 | 강의료, 광고, 기업 교육 | 깔끔 | 낮음 | 기존 유튜브·강의 프로젝트와 재활용 |
| 정부 지원사업·공공 용역 | 정부 | 지원금, 용역비 | 깔끔 | — | 창업 초기 자금(예비창업패키지 등) |

## 추천 로드맵: 바로 돈 + 기술 축적

| 단계 | 기간 | 할 일 | 수익원 |
|---|---|---|---|
| 0. 준비 | 0~1개월 | 사업자등록, 의뢰서·동의서·파기확인서 양식, 개인정보처리방침, 가격표, 배상책임보험. 동시에 디지털포렌식전문가 2급 준비 | — |
| 1. 실패 없는 서비스부터 | 1~3개월 | **스파이앱 점검, 본인 백업 기반 대화 증거 정리(AI 보고서), 데이터 완전삭제** — 복구 성공률 리스크가 없는 것만 | 개인 B2C, 변호사·노무사 제휴 |
| 2. 복구 추가 | 3~9개월 | 논리 복구부터 시작, 물리 손상은 **전문 복구 업체에 외주(소개 수수료)** | 복구·추출 |
| 3. 기업 패키지 | 6~12개월 | 퇴사자 유출 점검, 자산 폐기 삭제 인증 | B2B 정기계약 |
| 4. 도구화 | 6개월~ | 1~3단계에서 쓰던 보고서 생성기·사건 관리 도구를 다듬어 다른 업체에 판매 | SaaS 구독 |
| 5. 장기 | 2~3년~ | 실적·인증을 쌓아 공공 납품 검토 | B2G |

### 기술이 아직 없는 지금 할 수 있는 현실적인 방법
- **역할 분담 창업**: 영업·고객 응대·AI 보고서는 내가, 추출·복구 실무는 경력 있는 파트너나 외주 업체가. 내가 기술을 따라잡는 동안 매출이 난다.
- **업계 경험 먼저**: 민간 포렌식 업체에서 몇 개월 일하거나 외주로 붙어 실제 의뢰 흐름·가격·고객 유형을 배운다.

## 사용자가 정해야 할 것

1. 첫 6개월을 어느 쪽으로 갈지
   - A. 실패 없는 서비스(스파이앱 점검·증거 정리·완전삭제)로 1인 시작 **(추천)**
   - B. 기술 파트너와 공동 창업해 복구까지 처음부터
   - C. 업체에서 경험을 쌓고 나서 창업
2. 다음 작업
   - 경쟁업체 가격·광고 조사(researcher) → 숫자 확정 **(추천, 1번 선택 전에 하면 좋음)**
   - 서비스 상품 구성·가격표·의뢰서 양식 기획(planner)
   - AI 대화 증거 보고서 프로토타입 개발(developer)
