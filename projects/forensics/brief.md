# 프로젝트: 디지털 포렌식 공부 → 실무·AI 사업 연결

## 목표
- 디지털 포렌식 실무 지식을 체계적으로 익힌다 (정의는 알고 있음, 실무 지식이 없는 상태에서 시작).
- 포렌식 + AI 결합 사업 기회를 파악한다.
- 한국·세계 포렌식 수준과 사업모델 차이를 이해하고, 내가 들어갈 자리를 찾는다.

## 결과물 형태
- 학습 정리 문서(`outputs/*.md`), 구성 시각화(HTML 아티팩트), 이후 학습 로드맵·실습 기록

## 담당 에이전트
- 메인 세션(직접) → 필요 시 researcher(시장·수치 조사) → planner(사업 아이템 기획) → lecture-writer(오디오 강의화)

## 필요한 스킬
- 없음(현재). 실습 단계에서 `forensic-lab`(실습 환경·증거 해시 기록 절차) 스킬 검토

## 제약 / 참고
- 실제 타인 기기·데이터 분석은 법적 권한(동의·영장·계약) 없이 하지 않는다. 실습은 공개 실습 이미지로만.
- 출퇴근길 오디오 학습 선호 → 기초 내용은 클로드 강의처럼 오디오 대본으로 재활용 가능
