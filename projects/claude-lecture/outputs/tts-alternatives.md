# 일레븐랩스 대체 무료 TTS 후보 (2026-11-13 조사)

> 업체 블로그 위주 자료라 순위는 참고만. 한국어 품질은 같은 대본 한 단락으로 직접 들어보고 비교할 것.
> 무료 플랜의 상업 이용(광고 붙은 유튜브) 가능 여부는 각 공식 약관에서 재확인 필요.

## 1순위 후보
- **Google Cloud TTS** — 무료 사용량이 매월 생김(공식 페이지 기준 Standard·WaveNet 월 400만 자까지 무료). 1화 분량(약 5,000자)이면 12화 전체가 무료 범위. 상업 이용 가능한 유료 API 약관이라 유튜브용으로 안전한 편. 단점: 카드 등록·API 설정 필요. Chirp 3 HD(고품질) 무료량은 ⚠️ 미확인.
- **Microsoft Edge 읽어주기 음성 (edge-tts)** — 선히(여성), 인준(남성) 등 한국어 신경망 음성. 무료·설치 간단, 품질 좋음. 단, 공식 API가 아니라 상업 이용 약관이 불분명 ⚠️. 정식으로 쓰려면 Azure TTS(무료 월 사용량 있음).
- **클로바더빙 / 타입캐스트** — 국산이라 한국어 억양이 가장 자연스러움. 무료 플랜은 체험용 성격이 강하고 상업 이용 조건 ⚠️ 미확인.

## 내 PC에서 돌리는 오픈소스 (완전 무료, 설치 필요)
- **CosyVoice 2** — 한국어 지원이 가장 분명. 목소리 복제 가능.
- **GPT-SoVITS** — 한국어 지원, 짧은 샘플로 목소리 복제.
- **MeloTTS** — 가볍고 한국어 지원, 품질은 중간.
- Kokoro, Fish Speech, Chatterbox는 한국어 지원 여부가 자료마다 달라 ⚠️ 미확인.

## 추천
1. 우선 Google Cloud TTS(WaveNet 또는 Neural2 한국어 음성)로 1화 한 단락 샘플 → 무료·상업 이용 안전.
2. 같은 단락을 클로바더빙 무료 체험, edge-tts로 만들어 귀로 비교.
3. 마음에 드는 것으로 정하면 media-producer가 대본 → 음성 일괄 변환 스크립트 작성.
