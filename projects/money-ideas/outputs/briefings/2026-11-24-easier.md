# 2026-11-24 "더 쉽게 시작할 수 있는" 새 아이디어 3개

> 사용자: "단종 부품 복원이 쉬운 일이 아니어 보인다, 다른 건 없나" → I-013 보류, **혼자서 1~2주 안에 시작 가능한 것** 위주로 새로 찾음(경쟁 확인 각 2회).

### I-021 "이 자리 몇 번 망했나" — 상가 자리 폐업 이력 조회 — 23/30
- 무엇: 상가 주소를 넣으면 **그 자리에 그동안 어떤 가게가 들어왔다 몇 년 만에 나갔는지**를 보여준다(인허가 개·폐업 공공데이터). 예비 창업자·임차인·권리금 협상용. 무료 조회 + 상세 리포트 유료(건당).
- 근거: 서울시 상권분석서비스는 **행정동·업종 단위** 개·폐업률·생존율을 주지만 특정 주소의 이력 조회는 확인 안 됨. 서울시 상가업소 공공데이터에 '점포이력' 항목이 있음. [서울시 상권분석서비스](https://golmok.seoul.go.kr/main.do), [상가업소 공공데이터](https://www.data.go.kr/data/15146823/fileData.do)
- 이미 하는 곳: 공공 상권분석(동·업종 단위), 유료 창업 입지 컨설팅(크몽). **"이 주소의 폐업 역사"를 한 번에 보여주는 앱은 검색 2회에서 못 찾음.** [크몽 입지 컨설팅](https://kmong.com/gig/781120)
- **왜 나만**: 글로우버거를 직접 차리고 접어 본 사람 → "계약 전에 이걸 알았으면" 하는 정보를 정확히 앎. 투찰률 분석처럼 공공데이터로 남이 못 보는 패턴을 뽑는 감각.
- 쉬운 이유: 공공데이터 + 웹페이지 하나, 혼자 1~2주. 처음엔 평택·화성만.
- 위험: 지방은 데이터 정밀도가 서울보다 낮을 수 있음, 개인정보(상호·대표자) 노출 주의.

### I-022 중고 그래픽카드 "건강검진 USB" + 인증서 — 21/30
- 무엇: 중고 GPU를 사고팔 때 USB로 부팅해 온도·VRAM 오류·성능을 15분간 검사하고 **결과 인증서(QR)**를 발급. 판매자는 글에 붙이고, 구매자는 직거래 현장에서 확인.
- 근거: 커뮤니티에 "채굴 카드는 일반인이 확인 못 한다", 고장 우려 글 다수, 전문가 의견도 엇갈림 → 불신이 큼. [퀘이사존](https://quasarzone.com/bbs/qf_vga/views/6015536), [ITWorld](https://www.itworld.co.kr/article/3563773/)
- 이미 하는 곳: 채굴 이력을 가려주는 공인 인증·검수 서비스는 검색 2회에서 못 찾음(플랫폼 검수 문구 정도).
- **왜 나만**: 무결성 검사 경력 + 4090을 쓰는 PC 덕후 → 검사 결과를 위조 못 하게 만드는 쪽을 앎. (어제 아이디어 I-017 '삭제 인증 QR'과 합치면 "중고 PC 부품 검진+삭제" 하나로 묶을 수 있음)
- 위험: 채굴 이력 자체를 100% 판별하긴 어려움 → "지금 상태" 인증으로 범위를 정해야 함.

### I-023 남의 마당을 시간 단위로 빌려주는 "대형견 마당 공유" — 20/30
- 무엇: 개인 주택 마당·빈 창고 앞마당을 가진 사람이 비는 시간에 대형견 보호자에게 시간 단위로 빌려주는 연결 서비스(미국 Sniffspot 방식).
- 근거: 국내는 **업체가 운영하는 대관 운동장**(소노펫 50분 9만~12만 원, 동두천 2시간 3.5만 원 등)만 있고, 개인 마당 공유 플랫폼은 확인 안 됨. 미국 Sniffspot은 마리당 시간당 5~15달러. [소노펫](https://www.sonohotelsresorts.com/complex_vp/facilitiesviewall/detail/ADD00131058), [피크닉댕댕](https://www.daangn.com/kr/local-profile/%ED%94%BC%ED%81%AC%EB%8B%89%EB%8C%95%EB%8C%95-so588ssxhamm/), [Sniffspot](https://sniffspot.com/)
- **왜 나만**: 마당 있는 집·리트리버를 꿈꾸는 당사자 + 임대·공간 운영 감각. 처음엔 당근 동네 모집으로 시작 가능.
- 위험: 양쪽 사용자를 모아야 함, 개 물림·시설 파손 보험.
