# 2026-11-19 새 기준 추천 3개 (경쟁 확인 2회+, "왜 나만" 필수)

### I-012 중소 쇼핑몰용 "선착순·한정판 매크로 감지" 플러그인 — 22/30
- 무엇: 카페24·자사몰의 한정판·선착순 이벤트에 붙이는 저가 플러그인. 매크로 의심 주문을 점수로 표시하고, 이벤트가 끝나면 "진짜 고객 비율" 리포트를 낸다.
- 이미 하는 곳: **STCLab 봇매니저**(대기열 '넷퍼넬' 회사, AI 스코어링, 무상 PoC, 가격 비공개 → 대기업·티켓팅 중심). [STCLab](https://cloud.stclab.com/blog/new-botmanager-features) / 카페24용 매크로 차단 앱은 검색 2회에서 못 찾음(크몽 외주 개발만). [크몽 예시](https://kmong.com/gig/802123)
- 틈새: 대기업 솔루션은 비싸고 영업형 → **월 몇만 원짜리 셀프 설치형**은 비어 있음(확인 필요: 카페24 앱스토어 직접 확인).
- **왜 나만**: 유저/커널 모드 키보드 매크로 드라이버와 우회 탐지를 직접 설계해 봄 → 매크로를 **만드는 쪽의 생각**을 안다.
- 위험: 탐지 오판으로 진짜 고객 차단 → 처음엔 "차단"이 아니라 "표시·리포트"만.

### I-013 단종 부품 "사진 → 복원 → 출력" + 부품 도면 라이브러리 — 22/30
- 무엇: 부러진 플라스틱 부품(가전 손잡이·걸쇠·캡·노브 등)의 사진과 줄자 치수를 받으면 3D 모델을 만들어 출력·배송한다. 만든 도면은 라이브러리에 쌓아 **같은 부품이 다시 팔리게** 한다.
- 이미 하는 곳: 크몽 프리랜서의 건별 모델링·출력 대행(단순 1만 원~, 복잡 15만 원~), 산업용 3D 스캔·역설계 업체(레플리카 등). **가전 부품 전용 개인 의뢰 플랫폼·도면 라이브러리는 검색 2회에서 못 찾음**. [크몽](https://kmong.com/gig/736271), [레플리카 사례](https://replica0.tistory.com/82), [사진→3D 방법](https://jlc3dp.com/kr/blog/how-to-turn-photo-into-3d-model)
- 틈새: 건당 외주(매번 새로 그림)가 아니라 **한 번 그린 부품을 모델명으로 계속 파는 구조**(1→N 재활용).
- **왜 나만**: 원리를 파고드는 DIY 성향, RTX 4090(사진→3D AI 실험), 3D 프린터 꿈, 수리를 스스로 하는 습관. AI·메이커 실험실과 바로 연결.
- 위험: 정품 디자인·특허(일반 정보, 확인 필요), 강도·내열 문제 → 내열 필요 부품은 제외.

### I-014 "아무도 안 보는 공매" 레이더 — 21/30
- 무엇: 온비드 공매 중 **부동산 말고 동산**(기계장비·차량·물품·운영권 등 이색 물건)을 매일 훑어, 중고 시세 대비 싸게 나온 것을 알려준다. 처음엔 내가 직접 사서 되파는 데 쓰고, 맞히는 비율이 쌓이면 구독으로 판다.
- 이미 하는 곳: 온비드 공식(무료, 검색·알림), 지지옥션·탱크옥션(법원경매·부동산 공매 분석 중심, 동산 분석 여부는 확인 안 됨), 공공데이터에 낙찰가율 통계와 물건 조회 API 있음. [공공데이터 낙찰가율](https://www.data.go.kr/data/15140290/fileData.do), [탱크옥션](https://apps.apple.com/kr/app/%ED%83%B1%ED%81%AC%EC%98%A5%EC%85%98-%EC%A0%84%EA%B5%AD%EC%9D%98-%EB%AA%A8%EB%93%A0-%EB%B2%95%EC%9B%90%EA%B2%BD%EB%A7%A4-%EA%B3%B5%EB%A7%A4-%EB%B6%80%EB%8F%99%EC%82%B0-%EC%A0%95%EB%B3%B4/id6751822415?l=ko), ["별걸 다 파는 공매" 기사](https://www.mt.co.kr/article/2007110712003698739)
- 틈새: 분석 서비스가 몰린 부동산 대신 **사람들이 안 보는 동산·이색 물건**.
- **왜 나만**: 지역별 투찰률을 분석해 15억을 따낸 "낙찰가 읽는 감각"을 **완전히 다른 시장(사는 쪽)**에 씀. 이상한 물건을 좋아하는 취향 자체가 무기.
- 위험: 물건 상태 확인이 어려움(현장 확인 필요), 되팔기는 시간이 듦, 입찰보증금 필요. 입찰 플랫폼과 비슷해 보이지만 **파는 쪽 입찰 → 사는 쪽 투자**로 방향이 반대.
