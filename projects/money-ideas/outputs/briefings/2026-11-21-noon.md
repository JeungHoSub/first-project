# 2026-11-21(토) 점심 브리핑 — I-014 공매 레이더 심층 요약 (21 → 20/30)

> 답 대기 중이라 이번 점심은 **이미 선택된 I-014 심층만** 하고, 새 아이디어 3개는 답이 오면 재개(웹검색 3회).

## 데이터 (만들 수 있나)
- 공공데이터포털에 온비드 OpenAPI가 여럿 있음: 부동산 물건목록·상세·입찰결과는 **부동산 전용**, 동산·자동차는 **'순위물건' API(물건유형: 부동산|동산|자동차)**로만 확인됨 — 입찰 마감 전 물건만, 저감률 순위 등. [순위물건 API 카탈로그](https://data.go.kr/catalog/15157252/openapi.json), [부동산 물건목록](https://data.go.kr/catalog/15157207/openapi.json)
- 공고목록 API에 동산 코드가 있는지는 활용가이드 확인 필요. [공고목록](https://www.data.go.kr/data/15157216/openapi.do)
- 낙찰가율 통계는 압류재산 지역별(부동산 중심). [낙찰가율 통계](https://www.data.go.kr/data/15140290/fileData.do)
→ **동산 레이더는 '저감률 순위' API + 공고 크롤링 조합**으로 시작 가능. 낙찰 결과(실제 낙찰가) 데이터가 부족해 "얼마에 낙찰될지" 예측 모델은 처음엔 어려움.

## 돈이 되는 구조
- 유찰 시 약 1주 뒤 재공매, **회차마다 최저가 10%씩 하락**(물건별 공고 확인 필요) → 유찰이 반복되는 동산을 추적하면 시세보다 크게 싼 시점을 잡을 수 있음. [글래스월렛 온비드 가이드](https://glasswallet.com/blog/public-auction-onbid-guide)
- 압류재산 공매에는 기계장비·유가증권·골프 회원권 등도 나옴. [SBS Biz](https://biz.sbs.co.kr/amp/article/20000279561)

## 위험 (가장 큼)
- 동산은 **현장 확인·하자 책임·인도 절차가 부동산보다 불명확**하고, 공고 오류 시 낙찰이 취소될 수 있다는 조건이 붙기도 함. 대금 기한을 넘기면 보증금 몰수. [법률 칼럼](https://albup.co.kr/page/column_detail.php?content_id=1798), [보증금 몰수 사례](https://landvalueup.hankyung.com/?p=13422)
- 기계장비는 운송·철거·재판매 비용이 커서 싼 데는 이유가 있음(일반 추정).

## 1~10단계 자동화
물건 수집 ✅ / 저감률·유찰 횟수 추적 ✅ / 중고 시세 대조 ✅(당근·중고 사이트 시세, 일부 수작업) / 알림 ✅ / 현장 확인(사람) / 입찰(사람) / 인수·운송(사람) / 재판매 등록 ✅ / 판매(사람) / 수익 기록 ✅ → **정보 단계는 자동, 거래 단계는 사람**.

## 결론
- 구독 서비스로 팔기 전에 **"내가 직접 1~2건 사서 되팔아 보는" 실험**이 먼저. 정보 레이더만 만드는 건 1~2주면 됨.
- 점수 20/30: 지불 의사 3 · 자동화 3 · 비용 대비 수익 4 · 첫 매출 3 · 새로움 4 · 위험 3
