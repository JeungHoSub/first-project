# 2026-11-18 점심 브리핑 — I-001 조달 서류 비서 심층 조사

## 한 줄 요약
"인증 만료를 놓쳐 입찰 자격을 잃는" 문제는 실제로 있고, 이를 겨냥한 전용 서비스는 찾지 못했다. 다만 가격·수요 규모는 공개 자료가 없어 **직접 확인(인터뷰)이 필요**하다. 점수 25 → **24/30**.

## 문제가 진짜인가
- 직접생산확인증명서는 유효기간이 **2년**(지정기간 또는 변경지정일 중 먼저 오는 날까지)이고, **만료 전에 재신청하지 않으면 바로 입찰 자격을 잃는다**. 그래서 "유효기간 관리가 실무의 핵심"이라는 설명이 있다. [K-incorp 가이드](https://k-incorp.org/blog/corporate-direct-production-verification-certificate-guide-2026)
- 만료 **30일 이내**에 재신청하면 만료일 다음 날부터 2년이 이어지고, 만료 뒤에는 신규 신청과 같은 절차를 밟아야 한다(행정사 블로그, 공식 원문 확인 필요). [guard1004](https://www.guard1004.com/587)
- 중소기업확인서는 보통 **1년** 유효하고, 갱신 가능 시점이 결산·법인세 신고와 엮여 있어 헷갈린다(출처마다 설명이 다름). [jobis 도움말](https://help.jobis.co/hc/ko/articles/360001545713), [K-incorp](https://k-incorp.org/blog/corporate-sme-confirmation-certificate-issuance-guide-2026)
- 신청·수수료 납부는 공공구매종합정보망(SMPP), 발급은 중소기업중앙회. [K-incorp](https://k-incorp.org/blog/corporate-direct-production-verification-certificate-guide-2026)
→ 인증마다 주기·기준일이 달라 **사람이 달력으로 관리하기 어려운 구조**. 사용자가 실무에서 직접 겪은 문제와 같다.

## 시장 규모 (간접 지표)
- 다수공급자계약(MAS)에만 **1만 3,223개 기업**이 등록(2025-12말, 조달청 보도). 입찰 참가 등록 업체 전체는 이보다 훨씬 많을 것으로 추정. [조달청](https://www.pps.go.kr/kor/bbs/list.do?key=01326)
- 등록 업체 목록은 공공데이터포털 "조달업체 등록 내역"으로 집계 가능 → 나중에 영업 대상 목록으로도 쓸 수 있다. [data.go.kr](https://www.data.go.kr/data/15053474/fileData.do)

## 경쟁
| 대상 | 내용 | 우리와 차이 |
|---|---|---|
| 인증 대행 행정사·컨설팅 | 신청 대행 중심, 만료 관리는 부가 서비스 | 건당 대행. 자동 알림·여러 인증 통합 관리는 안 보임 |
| 크몽 인증 대행 | 벤처인증 상담 2만~5만 원 수준은 보이나 직접생산확인 대행 가격은 검색되지 않음 | [크몽](https://kmong.com/gig/674969) |
| SSL 인증서 관리(UCLM, 키팩터 등) | "만료 사전 알림·자동 갱신"을 파는 시장이 이미 있음 | IT 인증서용이라 조달 인증과 무관. 다만 **"만료 관리에 돈을 낸다"는 근거** [보안뉴스](https://m.boannews.com/html/detail.html?idx=137934) |
→ **조달 인증 전용 만료 관리 서비스는 검색 범위 안에서 못 찾음**(없다는 확정은 아님).

## 실행 1~10단계와 자동화
| 단계 | 내용 | 자동화 |
|---|---|---|
| 1 | 고객의 보유 인증 목록 입력 | 반자동(엑셀 업로드·카톡) |
| 2 | 인증별 만료일·재신청 가능일 계산 | ✅ |
| 3 | 90/30/7일 전 알림(카톡·문자·캘린더) | ✅ |
| 4 | 인증별 필요 서류 체크리스트 발송 | ✅ |
| 5 | 서류 준비 | 고객 |
| 6 | SMPP·SMINFO 신청 | 고객 (대행은 행정사 업무 해당 여부 확인 필요) |
| 7 | 현장조사 대응 | 고객 |
| 8 | 발급 확인·만료일 갱신 | ✅ |
| 9 | 다음 주기 자동 등록 | ✅ |
| 10 | 월간 리포트 | ✅ |
→ **10단계 중 6단계 자동**, 서비스는 "알림 + 체크리스트"까지만 하면 법 문제를 피하고 운영 시간이 거의 들지 않는다.

## 비용·가격 (가설)
- 운영비: 카톡 알림톡 건당 수 원~십수 원 + 소형 서버 → 월 1만 원대 예상(확인 필요).
- 가격 가설: 업체당 월 9,900~19,900원, 또는 연 10만 원. 행정사·컨설팅 업체용(고객사 여러 개 관리)은 월 5만 원대.

## 위험
- 인증별 규정이 바뀌면 계산 규칙을 고쳐야 함 → 규정 원문 관리가 필요.
- 서류 작성·제출까지 해주면 행정사법 문제 가능 → **알림·안내까지만**(일반 정보, 전문가 확인 필요).
- 수요 크기 미확인 → 아는 업체 3~5곳에 "이거 월 1만 원이면 쓰겠냐" 물어보는 게 가장 싼 검증.
