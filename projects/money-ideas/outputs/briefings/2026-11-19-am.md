# 2026-11-19 아침 브리핑 — 새 아이디어 3개

## 한 줄 요약
돈이 들지 않는 "PC로 버는 패시브 수입" 1개, 본인이 직접 겪은 문제 2개(임대 관리, 점포 양도).

### I-006 RTX 4090 유휴 시간 GPU 임대 — 23/30
- 무엇: 부업에 PC를 안 쓰는 시간(낮 등)에 Vast.ai 같은 GPU 마켓에 4090을 빌려준다. 설정 후 손이 거의 안 감.
- 얼마: 4090 임대 호가 중간값 시간당 약 $0.48, 평균 $0.28~0.35 수준이라는 자료가 있음. [computeprices](https://computeprices.com/providers/vast/gpus/rtx4090), [deploybase](https://deploybase.ai/articles/rtx-4090-vastai). 가동률 42%에 월 약 $340이라는 사례는 홍보성 글이라 신뢰도 낮음. [quakr 블로그](https://quakr-site.pages.dev/blog/cloud-gpu-rental-passive-income-2026)
- 자동화: 10/10 (예약 시간에만 대여 켜기)
- 기존 프로젝트와 다른 점: 무언가를 만들어 파는 게 아니라 **가진 장비로 바로 버는 수입**. 개발 크레딧 0.
- 위험: 부업 PC와 같은 기기면 보안·성능 충돌 → 별도 저장장치·계정 분리 필요. 전기료(4090 약 450W)·발열·수명. 저가 등급은 작업이 중간에 회수될 수 있음.

### I-007 폐업 점포 "통째 양도" 매칭 + 철거 지원금 안내 — 22/30
- 무엇: 폐업하려는 사장님이 시설·간판·장비를 **철거하지 않고 다음 임차인에게 넘기도록** 매칭하고, 정부 철거·폐업 지원금 중 무엇을 받을 수 있는지 자동 안내.
- 근거: 서울신용보증재단 2026 「새 길 여는 폐업지원」은 철거·원상복구비, **기자재 보관료·재판매용 수리·세척비**까지 지원 항목으로 둠(업체를 통한 철거만 인정, 희망리턴패키지와 중복 불가). [공고문](https://grant-documents.thevc.kr/291944_2026%EB%85%84_%EC%83%88_%EA%B8%B8_%EC%97%AC%EB%8A%94_%ED%8F%90%EC%97%85%EC%A7%80%EC%9B%90_%EC%82%AC%EC%97%85_%EB%AA%A8%EC%A7%91_%EA%B3%B5%EA%B3%A0%EB%AC%B8.pdf). 2026년 폐기물 처리비 상승으로 철거비 부담이 커졌다는 업계 글 다수(블로그, 참고용). [예시](https://blog.hansungshowcase.kr/2026-eb57a8a5)
- 검색 범위에서 **시설 양도 전용 매칭 서비스는 찾지 못함**(철거업체 홍보글만 많음).
- 기존 프로젝트와 다른 점: 가게를 **운영**하는 게 아니라, 직접 겪은 **폐업·양도 과정 자체를 플랫폼화**. 업종 무관(학원·네일샵·카페 등).
- 위험: 부동산 중개(권리금 거래) 해당 여부 확인 필요 — "정보 연결"까지만. 양쪽 사용자를 모아야 하는 닭과 달걀 문제.

### I-008 1~10호실 개인 임대인용 자동 관리 — 20/30
- 무엇: 월세 입금 확인 → 미납 카톡 알림 → 계약 만료 90일 전 알림 → 연말 임대소득 신고용 장부 자동 작성. 본인(전대차·오피스텔 검토 중)이 먼저 쓰고 판매.
- 경쟁: 홈버튼(호실 수별 구독, 위탁관리사·중대형 중심), 무료 앱 '집주인'(알림 위주, 기기 저장), 동거동락, 크몽 엑셀 시트. [홈버튼 요금 안내](https://docs.channel.io/homebutton/ko/categories/3-%ED%99%88%EB%B2%84%ED%8A%BC-%EC%9D%B4%EC%9A%A9%EC%9A%94%EA%B8%88-03ae729c), [집주인 앱](https://apps.apple.com/kr/app/%EC%A7%91%EC%A3%BC%EC%9D%B8-%EC%9E%84%EB%8C%80%EA%B4%80%EB%A6%AC%EB%A5%BC-%ED%8E%B8%ED%95%98%EA%B2%8C/id6744602173)
- 기존 프로젝트와 다른 점: 부동산 임대 시장(새 영역).
- 약점: 경쟁 앱이 이미 여럿 → 차별점이 "세금 장부 자동화" 정도라 약함.
