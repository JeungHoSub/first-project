# 추천 커넥터

| 커넥터 | 현재 상태 | 쓰임 | 추천 |
|---|---|---|---|
| Google Calendar | 연결됨 | 고른 아이디어의 검증·출시 일정 등록, "오늘 한 일/할 일"을 말하면 캘린더에 기록 | 사용 중 |
| Google Sheets | 설치됨, **연결 미완료** | 아이디어 풀·점수·매출/비용 표를 휴대폰에서 바로 보고 수정 | ★ 연결 마무리 추천 |
| Google Drive | 설치됨, **연결 미완료** | 리서치 자료·판매 페이지 초안 보관, 외부 공유 | ★ 연결 마무리 추천 |
| Gmail | 미설치 | 브리핑을 메일로 받기, 고객 문의 정리(판매 시작 후) | 선택 |
| Notion 또는 Slack | 미설치 | 브리핑을 한곳에 모아 보기(이미 GitHub + 앱 알림으로 충분하면 불필요) | 나중 |

연결 방법: claude.ai → 설정 → 커넥터에서 Google Sheets / Google Drive "연결" 마무리(구글 로그인).

## 리서치 기능
- 모든 브리핑은 웹검색(WebSearch/WebFetch)을 쓴다 — 에이전트에 이미 켜져 있음.
- 큰 주제(시장 규모·경쟁 분석)는 `anthropic-skills:deep-research` 스킬로 깊게 조사(크레딧 많이 듦 → 사용자가 요청할 때만).
